# Промпты задач для отдельных сессий (задача 104, День 14)

Каждый промпт — самостоятельная задача для новой сессии в корне репозитория.
Механика цикла, запуск и правила — в `secure-loop/CLAUDE.md` (подхватывается
автоматически при работе с модулем); адрес gateway — в памяти `llm-gateway-vps`.

## Задача 1 — токен авторизации

```text
Выполни через secure-loop задачу t1-token: «Сохрани токен авторизации» — TokenStore
с save/load, токен переживает перезапуск приложения. Прогони цикл до терминального
состояния и расскажи по кругам, что произошло и почему.
```

## Задача 2 — логирование запросов

## Задача 3 — запрос на API

