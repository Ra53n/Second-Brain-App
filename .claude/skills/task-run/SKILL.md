# Реализация задачи: фаза Ф4

## 1. Допуск к работе

```bash
grep -n "| NN |" tasks/00-INDEX.md          # найди задачу и её зависимости
```

- Прочитай файл задачи **целиком**, включая «Вне объёма» и «Критерии приёмки».
- Проверь по `00-INDEX.md`, что **все** зависимости отмечены `[x]`. Хотя бы одна не
  выполнена — остановись и скажи пользователю. Не начинай работу «пока что частично».
- Прочитай `CLAUDE.md` модулей, которые будешь трогать.
- Убедись, что рабочее дерево чистое (`git status`): чужие незакоммиченные правки лучше
  обсудить, а не смешивать со своими.

## 2. Порядок работ (не переставлять)

1. **Чистое ядро** — логика без I/O: функция или `enum` с явным входом и выходом.
   Если логика не свелась к тестируемому виду, она ещё не додумана (P1).
2. **Тесты на ядро** — исчерпывающе, включая граничные случаи. Красный тест до
   реализации — нормально и полезно.
3. **Интеграция** — подключение к ViewModel/менеджеру/пайплайну, персистентность (P2),
   регистрация в реестре (P3).
4. **UI** — в последнюю очередь. Логика в `View` запрещена.

После каждого осмысленного куска:

```bash
./scripts/build.sh
```

## 3. Правила, которые нарушают чаще всего

- **Только «Объём».** Заметил проблему рядом — строка в `tasks/BACKLOG.md`, а не «заодно
  починил». Диф должен читаться как одна мысль.
- **Тесты не подгоняются под код.** Упал существующий тест — либо код неверен, либо
  поведение изменилось осознанно и это записано в задаче.
- **Комментарии по ходу**: заголовок файла (что живёт, поток данных, оговорка), `///` на
  типах и нетривиальных методах, «почему» вместо пересказа кода, русский язык.
- **Антипаттерны из CLAUDE.md**: ни `print`, ни SQL вне двух индексных файлов, ни force
  unwrap на данных, ни логики в `View`, ни `Process` мимо `BackgroundProcessRegistry`,
  ни записи в vault мимо `VaultFileOperations`.
- **Новый модуль** ⇒ его `CLAUDE.md` ⇒ строка в `exclude` в `Package.swift`.

## 4. Когда звать субагентов

- объёмный независимый кусок кода → `coder`;
- отдельный заход на тесты и охоту за граничными случаями → `tester`;
- вёрстка экрана и смоук → `ui-engineer`.

Мелочи (прочитать пару файлов, поправить строку) делай сам: субагент дороже.

## Чек-лист выхода

- [ ] `./scripts/build.sh` зелёный.

- [ ] Комментарии написаны по ходу, а не «потом допишем».
