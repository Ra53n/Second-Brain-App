# Портирование из Manager Assistant

`/Users/kostyanikitin/Desktop/Manager assistant` — работающее приложение владельца на том
же стеке. Оно источник проверенных решений: половина подсистем Second Brain портирована
оттуда. Прежде чем изобретать своё — проверь, нет ли там готового.

## 1. Найди аналог

Таблица «Что портировать из Manager Assistant» — в `docs/CONVENTIONS.md`, с абсолютными
путями файлов MA и номерами задач, где они уже пригодились. Готовое есть для: FSM и
таблиц переходов, оркестратора FSM, персистентности и миграций, PromptBuilder, HTTP-клиента
LLM, всего RAG-пайплайна, MCP-клиента, лаунчера локального рантайма, входа в приложение,
сборки `.app`.

Нет в таблице — поищи по коду MA:

```bash
grep -rn "<ключевое слово>" "/Users/kostyanikitin/Desktop/Manager assistant/Sources" | head
ls "/Users/kostyanikitin/Desktop/Manager assistant/Tests/ManagerAssistantTests"
```

**MA — только для чтения.** Ничего в нём не меняем.

## 2. Портируй, а не копируй

1. Прочитай оригинал целиком, включая заголовочный комментарий: там обычно объяснено,
   почему сделано именно так, — это и есть главная ценность.
2. Перенеси в нужный модуль Second Brain, переименовав под наш домен и нейминг
   (`*Store`, `*Manager`, `*Provider`, `*Service`).
3. Адаптируй под наши инварианты: vault как источник истины, `BackgroundProcessRegistry`
   для процессов, `Config.appSupportDirectory` для производных данных.
4. **Комментарии переведи на нашу конвенцию** (минимум по делу, антипаттерн 9): плотные
   шапки MA сожми до 1 строки (+≤2 на неочевидную оговорку), `///` оставь только там, где
   имя+сигнатура не объясняют. Логику-«почему» из оригинала сохрани — она ценна.
5. Выброси то, что относится к домену MA (задачи, Jira-специфика) — не тащи мёртвый код.

## 3. Принеси тесты

Тесты MA портируются вместе с кодом: `FSMTests`, `MigrationTests`, `RagTests`, `MCPTests`
и подобные — готовые наборы случаев, которые уже ловили баги. Адаптируй имена и данные
под наш домен, сохрани структуру покрытия. Тест, который в MA проверял таблицу переходов
исчерпывающе, обязан делать это и здесь.

## 4. Зафиксируй происхождение

В заголовке портированного файла — строка вида
`// Порт <Файл>.swift из Manager Assistant (адаптировано под <домен>)`,
как в `AgentPhaseReducer.swift` («порт per-state switch из runStateMachine MA»).
Через полгода это единственный способ понять, где искать оригинальную мотивацию.
