# Смоук UI через Accessibility

## Почему не скриншоты

Окно SecondBrain исключено из захвата экрана (`kCGWindowSharingState = 0`) — любой
снимок отдаёт обои рабочего стола, а не приложение. Проверять UI можно только через
Accessibility API (`osascript`). Не трать время на скриншоты и не проси пользователя
посмотреть за тебя.

## Три грабли, на которые наступают все

1. **Приложение должно быть активно.** В фоне `window 1` не существует: `System Events`
   отдаёт `count of windows = 0` и ошибку -1719. Поэтому каждый скрипт начинается с
   `tell application "SecondBrain" to activate` + `delay 0.6`.
2. **Подпись элемента лежит в разных свойствах.** У `AXStaticText` — в `name`/`value`;
   у кнопок тулбара — в `description`; у SwiftUI-кнопок с иконкой подписи может не быть
   вообще (`description` вернёт локализованное «button»). Ориентир — соседний
   `AXStaticText` внутри той же ячейки.
3. **`entire contents of window 1` не работает** на этом приложении (возвращает пусто).
   Нужен ручной рекурсивный обход — он в `ax.applescript` рядом с этим файлом.
   `AXHandle` окна протухает при перестроении большого дерева: перезапрашивай `window 1`,
   а не переиспользуй ссылку между командами.

Отдельно: SwiftUI не отдаёт текст label у `DisclosureGroup` — строки-папки в дереве vault
выглядят для AX пустыми. Это поведение фреймворка, ориентируйся на имена файлов.

## Как пользоваться

Скрипт `ax.applescript` в каталоге скилла умеет два режима.

```bash
# Всё дерево окна: роль | подпись, с отступами по вложенности
osascript .claude/skills/smoke-ui/ax.applescript dump

# Нажать элемент по точной подписи (клик, при неудаче — AXPress)
osascript .claude/skills/smoke-ui/ax.applescript click "Встречи"
```

Разделы приложения открываются кликом по подписи в сайдбаре: `Заметки`, `Встречи`,
`Чат`, `Пайплайны`, `Настройки`.

Полезные фильтры вывода:

```bash
# только элементы с подписями
osascript .claude/skills/smoke-ui/ax.applescript dump | grep -v "| $"

# только кликабельное
osascript .claude/skills/smoke-ui/ax.applescript dump | grep -E "AXButton|AXPopUpButton|AXCheckBox"
```

## Процедура смоука

1. **Собери и установи то, что проверяешь:** `./install.sh`. Проверять старую сборку —
   классический способ потерять час.
2. **Перезапусти приложение сам:**
   ```bash
   osascript -e 'tell application "SecondBrain" to quit'; sleep 2
   open -a /Applications/SecondBrain.app; sleep 3; pgrep -lf SecondBrain
   ```
   Не проси об этом пользователя.
3. **Открой раздел** кликом по подписи и сделай `dump` — зафиксируй исходное состояние.
4. **Пройди по всем кнопкам затронутого экрана**: на каждую — `click`, затем `dump` и
   проверка, что состояние изменилось так, как обещает задача. Кнопка без подписи
   идентифицируется по соседнему тексту в той же ячейке.
5. **Проверь состояния, а не только нажатия:** чипы статус-строки показывают актуальное
   значение (например, «Транскрипция: Авто (Deepgram)»), пустые экраны показывают
   осмысленный текст, длинные значения не ломают вёрстку.
6. **Зафиксируй вывод в отчёте.** «Выглядит корректно» без AX-вывода смоуком не считается.

## Пример проверенного вывода (раздел «Встречи»)

```
AXPopUpButton | Оба
AXOutline | list
  AXRow → AXCell
    AXStaticText | 2026-07-19 12-22
    AXStaticText | 19 июля 2026 г., 12:22
    AXStaticText | 01:19
    AXStaticText | 2 дорожки
AXPopUpButton | Транскрипция: Авто (Deepgram)
```

## Чего не делать

- Не кликать вслепую в разделах, которые задача не трогает: приложение работает с живым
  vault пользователя, а часть кнопок запускает запись, индексацию или git-операции.
- Не вводить текст в поля живого vault и не сохранять заметки при проверке.
- Не удалять записи и заметки. Смоук — про «нажалось и показалось», а не про CRUD.
