# Смоук UI через Accessibility

## Почему не скриншоты

Окно SecondBrain исключено из захвата экрана (`kCGWindowSharingState = 0`) — любой
снимок отдаёт обои рабочего стола, а не приложение. Проверять UI можно только через
Accessibility API (`osascript`). Не трать время на скриншоты и не проси пользователя
посмотреть за тебя.

## Грабли, уже учтённые в `scripts/ui.sh` (не переизобретай)

1. **Окно появляется в AX не сразу после `activate`** — фиксированная задержка даёт
   ложное «окно не открыто» (-1719). В скрипте — опрос до 5 с плюс 0.4 с на то, чтобы
   окно стало key: клик раньше принимается без ошибки и молча игнорируется SwiftUI.
2. **`entire contents of window 1` возвращает пусто** — нужен ручной обход; подписи
   выбираются пакетно, иначе поиск стоит десятки секунд.
3. **Подпись лежит в разных свойствах:** `name`/`value` у `AXStaticText`, `description`
   у кнопок тулбара; у SwiftUI-кнопки с иконкой подписи может не быть вовсе.
4. **`osascript` виснет навсегда** на модалке или запросе прав Automation — поэтому
   таймаут обязателен, и поэтому голый `osascript` запускать нельзя.

Отдельно: SwiftUI не отдаёт текст label у `DisclosureGroup` — строки-папки в дереве vault
выглядят для AX пустыми. Это поведение фреймворка, ориентируйся на имена файлов.

## Как пользоваться

Всё через `./scripts/ui.sh` — там таймауты, preflight и восстановление окна.
Голый `osascript` не запускай: он виснет навсегда на модалке или запросе прав.

```bash
./scripts/ui.sh preflight              # процесс, свежесть сборки, окно
./scripts/ui.sh open Встречи           # раздел (с подтверждением, что открылся)
./scripts/ui.sh check "Транскрипция"   # PASS/FAIL одной строкой — основной инструмент
./scripts/ui.sh click "Сбросить"       # клик; необратимые кнопки блокируются
./scripts/ui.sh list                   # интерактивные элементы экрана
./scripts/ui.sh dump                   # всё дерево — дорого, только для разбора
./scripts/ui.sh run smoke/meetings.txt # сценарий: один компактный отчёт
./scripts/ui.sh restart                # лекарство от залипшего UI
```

**Проверяй ассертами, а не глазами.** `check` — одна строка вместо трёхсот; `dump`
допустим один раз, когда надо понять незнакомый экран.

**Навигация — ссылкой, а не кликом** (задача 50): `open` внутри использует
`secondbrain://section/<slug>` и подтверждает результат маркером раздела. Прямо
доступны `secondbrain://section/{notes,meetings,chat,pipelines,settings}` и
`secondbrain://settings/<вкладка>`. AX-клик по сайдбару остался фолбэком, но
полагаться на него нельзя — он срабатывает через раз.

Если `open` всё же отчитался «раздел не открылся»: сборка старее исходников
(`preflight` это ловит) или накопились лишние окна — лечится `restart`.

Разделы сайдбара: `Заметки`, `Встречи`, `Чат`, `Пайплайны`, `Тюнинг`, `Настройки`.

## Процедура смоука

1. **Собери и установи то, что проверяешь:** `./install.sh`. Проверять старую сборку —
   классический способ потерять час.
2. **Перезапусти приложение сам:**
   ```bash
   osascript -e 'tell application "SecondBrain" to quit'; sleep 2
   open -a /Applications/SecondBrain.app; sleep 3; pgrep -lf SecondBrain
   ```
   Не проси об этом пользователя.
3. **Открой раздел** (`open`) и один раз `list` — этого хватает, чтобы понять экран.
4. **Пройди по кнопкам задачи**: `click`, затем `check` ожидаемого изменения. Ассерт,
   а не дамп: одна строка вместо трёхсот. Кнопка без подписи ищется по соседнему тексту.
5. **Сложи повторяемые шаги в `smoke/<раздел>.txt`** и дальше гоняй `run` — один вызов,
   один отчёт, и это становится регрессионным сценарием.
6. **Проверь состояния, а не только нажатия:** чипы статус-строки показывают актуальное
   значение (например, «Транскрипция: Авто (Deepgram)»), пустые экраны показывают
   осмысленный текст, длинные значения не ломают вёрстку.
7. **Зафиксируй вывод в отчёте.** «Выглядит корректно» без AX-вывода смоуком не считается.

## Пример проверенного вывода (раздел «Встречи»)

```
AXPopUpButton | Оба
AXOutline | list
  AXRow → AXCell
    AXStaticText | 2026-07-19 12-22
    AXStaticText | 19 июля 2026 г., 12:22
    AXStaticText | 01:19
    AXStaticText | 2 дорожки
AXPopUpButton | Транскрипция: Авто (Deepgram)
```

## Чего не делать

- Не кликать вслепую в разделах, которые задача не трогает: приложение работает с живым
  vault пользователя, а часть кнопок запускает запись, индексацию или git-операции.
- Не вводить текст в поля живого vault и не сохранять заметки при проверке.
- Не удалять записи и заметки. Смоук — про «нажалось и показалось», а не про CRUD.
