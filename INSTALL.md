# Установка Second Brain на другой Mac

## Требования

- macOS 14 (Sonoma) или новее; для записи системного звука (вебинары, Zoom) — 14.4+.
- **Apple Silicon** (M1 и новее): сборка только arm64 — локальные модели
  (WhisperKit, Ollama) целятся именно в него, Intel не поддерживается.
- git уже есть в macOS (ставится с Command Line Tools: `xcode-select --install`) —
  нужен для синхронизации vault.
- Опционально: [Ollama](https://ollama.com/download) — локальные LLM;
  без него работают облачные провайдеры (ключи вводятся в настройках).

## Сборка дистрибутива (на Mac владельца)

```bash
./dist.sh    # → dist/SecondBrain-<версия>.dmg и .zip
```

Версия берётся из git-тега (`git tag v1.0 && ./dist.sh`), показывается в
меню «About Second Brain».

## Установка

1. Скопируйте `SecondBrain-<версия>.dmg` на целевой Mac и откройте.
2. Перетащите **Second Brain** в папку **Applications** (ярлык рядом).

### Если сборка нотаризована (ветка А: Developer ID)

Просто запустите приложение — Gatekeeper пропустит без вопросов.

### Если сборка ad-hoc (ветка Б: без Developer-аккаунта — текущая)

Gatekeeper заблокирует первый запуск («повреждено» / «неизвестный
разработчик»). Это штатно для неподписанных сборок; снимите карантин:

```bash
xattr -dr com.apple.quarantine /Applications/SecondBrain.app
```

Затем первый запуск — **правый клик по приложению → «Открыть» → «Открыть»**.
Дальше запускается как обычно.

> Важно: снимайте карантин только с приложений, которым доверяете (эту
> сборку вы собрали сами из своего репозитория).

## Первый запуск

1. Разрешите доступ к **микрофону**, когда macOS спросит (запись встреч).
2. Откройте vault: подойдёт существующая папка Obsidian.
3. `Cmd+,` — настройки: API-ключи провайдеров, модели, git-синхронизация.

## Ветка А на будущее (есть Apple Developer аккаунт, $99/год)

1. Установите сертификат **Developer ID Application** в Keychain
   (developer.apple.com → Certificates).
2. Один раз сохраните учётные данные нотаризации:
   `xcrun notarytool store-credentials second-brain-notary --apple-id <id> --team-id <team>`
   (App-Specific Password создаётся на appleid.apple.com; в скрипте не хранится).
3. `./dist.sh` сам найдёт сертификат, подпишет, нотаризует и пристеплит билет —
   установка на любом Mac без снятия карантина.
