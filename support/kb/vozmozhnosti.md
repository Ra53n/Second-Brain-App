# Возможности Second Brain

## Заметки («второй мозг»)

- Как vault выбирается любая папка — включая существующий Obsidian vault. Данные — обычные .md-файлы, никакого запирания формата.
- Дерево папок и файлов, создание любых файлов и папок.
- Markdown-редактор с live preview, `[[wikilinks]]` с автокомплитом, backlinks, YAML frontmatter — совместимо с Obsidian.
- Полнотекстовый поиск (SQLite FTS5) и quick switcher для быстрого перехода к заметке.

## Встречи

- Запись звука: микрофон и/или системный звук (собеседники в Zoom/Meet через Core Audio process tap; требуется macOS 14.4+).
- Пайплайн «запись → транскрипция → summary → заметка в vault» устроен как конечный автомат с ретраями и переживает перезапуск приложения.
- Транскрипция выбранным провайдером: локально (WhisperKit на устройстве, офлайн после скачивания модели) или облачно (OpenAI, Deepgram, AssemblyAI, Gemini). Провайдеров можно сравнивать на своих встречах.
- Готовая заметка автоматически кладётся в папку с датой и предложенным LLM названием; в заметке — summary, транскрипт и ссылка на аудиофайл. Правила раскладки настраиваются промптом.
- Записи хранятся в vault (`Meetings/_recordings/`) вместе с метаданными — они уезжают с vault при git-синхронизации.

## LLM и модели

- Единая абстракция провайдеров: чат, транскрипция, эмбеддинги.
- Роутинг «функция → провайдер+модель»: например, транскрипция — Deepgram, summary — Gemini, чат — локальная модель. Настраивается на вкладке «Модели».
- Локальные LLM через Ollama: приложение умеет запускать рантайм фоновым процессом по необходимости, гасить при простое и гарантированно завершать все дочерние процессы при выходе. Уже запущенный сервер Ollama используется как есть.
- API-ключи облачных провайдеров хранятся только в Keychain macOS (в интерфейсе — только статус «задан»); fallback — переменные окружения.

## Чат и RAG

- Чат со своей базой знаний на любой настроенной модели, с историей диалогов и выбором модели на каждый чат.
- RAG по vault: вопрос → релевантные заметки → ответ с цитатами-ссылками; клик по цитате открывает заметку.
- Настройки RAG на чат: включение, topK, порог релевантности, переписывание запроса, реранк.
- Вызов MCP-инструментов прямо из чата (Jira, Confluence и любые stdio-серверы) — конфиг в стиле Claude Desktop, секреты через Keychain.

## Синхронизация

- Git-панель прямо в приложении: commit/push/pull, история, разрешение конфликтов.
- Авто-бэкап по таймеру: изменения коммитятся регулярно, vault консистентен между несколькими Mac.
- Секреты (токены git-remote) — только в Keychain.

## Ограничения (вне целей продукта)

- Только macOS на Apple Silicon; мобильных и web-версий нет.
- Приложение однопользовательское, без облачного бэкенда и без плагиновой экосистемы как у Obsidian.
