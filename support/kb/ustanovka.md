# Установка и первый запуск

## Требования

- macOS 14 (Sonoma) или новее; для записи системного звука встреч (Zoom, Meet, вебинары) — macOS 14.4+.
- Apple Silicon (M1 и новее). Intel-Mac не поддерживается: сборка только arm64, локальные модели (WhisperKit, Ollama) работают именно на Apple Silicon.
- git — уже есть в macOS после установки Command Line Tools (`xcode-select --install`); нужен для git-синхронизации vault.
- Опционально: Ollama (ollama.com/download) — для локальных LLM. Без неё доступны облачные провайдеры.

## Установка из дистрибутива

1. Откройте `SecondBrain-<версия>.dmg`.
2. Перетащите Second Brain в папку Applications (ярлык лежит рядом).

## Первый запуск ad-hoc сборки (Gatekeeper)

Текущие сборки подписаны ad-hoc, без нотаризации Apple. Gatekeeper заблокирует первый запуск с сообщением «повреждено» или «неизвестный разработчик» — это штатно. Решение:

```
xattr -dr com.apple.quarantine /Applications/SecondBrain.app
```

Затем первый запуск — правый клик по приложению → «Открыть» → подтвердить «Открыть». Дальше приложение запускается обычным способом.

Снимайте карантин только с приложений, которым доверяете.

## Первый запуск приложения

1. Разрешите доступ к микрофону, когда macOS спросит — он нужен для записи встреч.
2. Откройте vault: подойдёт существующая папка Obsidian — приложение работает поверх обычных .md-файлов.
3. Нажмите Cmd+, — настройки: API-ключи облачных провайдеров, роутинг моделей, git-синхронизация.
