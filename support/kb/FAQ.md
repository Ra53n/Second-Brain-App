# FAQ по Second Brain

Ответы на частые вопросы пользователей приложения Second Brain.

## Что такое Second Brain?

Second Brain — персональное macOS-приложение «второй мозг»: хранилище связанных markdown-заметок (аналог Obsidian), дополненное записью и транскрипцией встреч, чатом с собственной базой знаний (RAG), MCP-интеграциями (Jira, Confluence и любые stdio-серверы) и git-синхронизацией vault. Приложение работает поверх обычных .md-файлов и не запирает данные: vault открывается в Obsidian.

## Какие требования к системе?

- macOS 14 (Sonoma) или новее. Для записи системного звука (собеседники в Zoom/Meet) нужна macOS 14.4+.
- Только Apple Silicon (M1 и новее): сборка arm64, Intel не поддерживается — локальные модели (WhisperKit, Ollama) целятся именно в Apple Silicon.
- git (ставится с Command Line Tools: `xcode-select --install`) — нужен для синхронизации vault.
- Опционально: Ollama для локальных LLM. Без неё работают облачные провайдеры (ключи вводятся в настройках).

## Почему при запуске пишет «приложение повреждено»?

Текущие сборки подписаны ad-hoc (без нотаризации Apple), поэтому Gatekeeper блокирует первый запуск — это штатное поведение для неподписанных сборок, а не реальное повреждение. Снимите карантин в Терминале:

```
xattr -dr com.apple.quarantine /Applications/SecondBrain.app
```

Затем первый запуск — правый клик по приложению → «Открыть» → «Открыть». Дальше приложение запускается как обычно. Снимайте карантин только с приложений, которым доверяете.

## Не работает авторизация при git push / pull — что делать?

«Авторизация» в Second Brain — это доступ git к удалённому репозиторию (например, GitHub), где синхронизируется vault. Ошибка «authentication failed» при push/pull почти всегда означает проблему с учётными данными git-remote:

1. Если репозиторий на GitHub по HTTPS — проверьте Personal Access Token (PAT): он мог истечь. Создайте новый на github.com → Settings → Developer settings → Personal access tokens и обновите его в настройках git-синхронизации приложения (Cmd+, → Git).
2. Секреты хранятся только в Keychain macOS — приложение никогда не пишет токены в файлы или git. В интерфейсе ключ не показывается, только статус «задан».
3. Проверьте, что у токена есть право на запись в репозиторий (scope repo).

Отдельного логина в само приложение нет — Second Brain однопользовательское, без облачного бэкенда.

## Что делать при конфликте git при работе с двух Mac?

Git-панель приложения показывает конфликтные файлы. Выберите нужную версию (или объедините вручную в редакторе), сделайте commit — после этого pull/push пройдут. Чтобы конфликтов было меньше, включите авто-бэкап по таймеру (коммиты уходят чаще).

## Почему в записи встречи нет голоса собеседников?

Собеседники (системный звук Zoom/Meet) записываются через Core Audio process tap, который требует macOS 14.4 или новее. На macOS 14.0–14.3 записывается только микрофон. Обновите macOS до 14.4+ и выберите режим записи с системным звуком.

## Транскрипция не работает или работает плохо — что проверить?

- Транскрипцию делает выбранный провайдер: локально WhisperKit (на устройстве) или облачно OpenAI, Deepgram, AssemblyAI, Gemini. Провайдер настраивается в роутинге «функция → модель» (Cmd+, → Модели).
- Локальная транскрипция (WhisperKit) слабее облачной — для важных встреч попробуйте облачного провайдера, сравните качество на своих записях.
- WhisperKit при первом использовании скачивает CoreML-модель (до нескольких ГБ) с huggingface.co — нужны место на диске и доступ к сети. После загрузки транскрипция работает полностью офлайн.
- Для облачных провайдеров должен быть введён API-ключ (Cmd+, → ключи провайдеров).

## Приложение не видит установленную Ollama

Приложение умеет находить Ollama и как внешний уже запущенный сервер, и как бинарь для запуска управляемым фоновым процессом. Если Ollama установлена в нестандартный путь, проверьте настройки локальных моделей: приложение ищет бинарь в стандартных местах (например, /Applications/Ollama.app, пути Homebrew, ~/ollama-dist). Уже запущенный `ollama serve` приложение использует как есть и не трогает при выходе; собственный запущенный процесс гасится при простое и гарантированно при выходе из приложения.

## Где хранятся мои данные и что можно безопасно удалить?

Два хранилища:

- **Vault** — папка, которую вы выбрали (Obsidian-совместимая). Это источник истины: заметки, записи встреч. Приложение никогда не удаляет и молча не перезаписывает ваши .md-файлы.
- **`~/Library/Application Support/SecondBrain/`** — настройки, истории чатов и встреч, поисковые и RAG-индексы (SQLite), кэш моделей WhisperKit. Индексы полностью пересоздаваемы: их удаление безопасно, приложение построит их заново.

API-ключи — только в Keychain macOS, в файлы и git они не попадают.

## Чат отвечает «в базе знаний ответа нет» — почему?

RAG-ответ строится только по заметкам вашего vault: если релевантных заметок нет или включён высокий порог релевантности, модель честно говорит, что не нашла ответа. Проверьте, что RAG включён в настройках чата, индекс построен, и попробуйте переформулировать вопрос. После смены модели эмбеддингов нужна полная переиндексация — до неё RAG молча выключается.

## Есть ли версия для Windows, iPhone или веб?

Нет. Second Brain — только macOS (Apple Silicon). Мобильные и web-версии, многопользовательность и облачный бэкенд — вне целей продукта. Vault при этом синхронизируется через git, поэтому заметки доступны на нескольких Mac.
