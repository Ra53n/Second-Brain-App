# Vision: Second Brain

## Что это

Персональное macOS-приложение — «второй мозг»: хранилище связанных заметок (аналог Obsidian), дополненное функциями, которых владельцу не хватает для работы: запись и транскрипция встреч, ИИ-раскладка транскрипций по базе, чат со своей базой знаний, интеграции с рабочими инструментами.

Пользователь — один человек (владелец), он же тимлид: много встреч, Jira/Confluence, уже ведёт Obsidian vault (`~/Documents/Obsidian Vault/Second_Brain`, синхронизируется с GitHub).

## Функции по приоритету

### 1. Второй мозг (ядро)
- Выбор **любой папки** как vault — включая существующий Obsidian vault. Приложение работает поверх обычных .md файлов и не запирает данные.
- Дерево папок/файлов, создание любых файлов и папок, хранение произвольной информации.
- Markdown-редактор, `[[wikilinks]]` с автокомплитом, backlinks, YAML frontmatter — совместимо с Obsidian.
- Полнотекстовый поиск и быстрый переход к заметке.

### 2. Встречи
- Запись звука: микрофон и/или системный звук (участники звонка в Zoom/Meet).
- Транскрипция **выбранным провайдером**: локально (Whisper на устройстве) или облачно (OpenAI, Deepgram/AssemblyAI, Gemini). Локальная транскрипция слабее — облако обязательно. Пользователь будет сам сравнивать провайдеров на своих встречах.
- После транскрипции заметка автоматически кладётся в логичную папку с датой и предложенным LLM названием; если название не задано заранее — предлагается на подтверждение, чтобы встреча не потерялась. Поведение раскладки настраивается промптом.
- В заметке: summary, транскрипт, ссылка на аудиофайл.

### 3. LLM-инфраструктура
- Единая абстракция провайдеров: чат, транскрипция, эмбеддинги.
- Роутинг «функция → провайдер+модель»: например, транскрипция — Deepgram, summary — Gemini, чат — локальная модель.
- Локальные LLM: установка/скачивание моделей, запуск рантайма фоновым процессом по необходимости, гашение при простое, гарантированное убийство всех дочерних процессов при выходе из приложения.

### 4. Чат и RAG
- Чат со «вторым мозгом» на любой настроенной модели (локальной или облачной).
- RAG по vault: вопрос → релевантные заметки → ответ с цитатами-ссылками, открытие заметки по клику.

### 5. Интеграции
- MCP-клиент: подключение MCP-серверов (в первую очередь Jira и Confluence) как инструментов в чате.

### 6. Синхронизация
- Git прямо из приложения: commit/push/pull, история, авто-бэкап по таймеру. Vault консистентен между несколькими Mac.

### 7. Дистрибуция
- Приложение собирается на машине владельца и запускается на любом другом Mac.

## Не-цели (пока)
- Мобильные и web-версии.
- Многопользовательность, облачный бэкенд.
- Плагиновая экосистема как у Obsidian.
