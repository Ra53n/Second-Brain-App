# Задача 90: статистика «последний запрос» отдельно от статистики сессии

## Тип

фича (малая)

## Модель

Fable 5

## Допущения и corner-кейсы

Фидбэк пользователя: одна агрегированная панель не даёт понять вклад конкретного
запроса — нужны два блока: (1) метрики последнего запроса, (2) агрегаты сессии треда.
Corner-кейсы: ответов нет → заглушка как раньше; один ответ → оба блока показывают
консистентные числа; последний ответ без report (ошибка) → блок запроса скрыт, сессия
считается по имеющимся отчётам; блоки разделены визуально, оба в AX-value.

## Архитектура

`TuningChatViewModel.lastReport: ConfidenceReport?` — report последнего ассистентского
сообщения активного треда (одна строка, чтобы не решать это во View — антипаттерн 5).
`FineTuneChatViews.sessionStatsSection` → два подблока: «Последний запрос» (вердикт-чип,
вызовы всего/доп., latency ответ/полная, токены) и «Сессия (N ответов)» (существующие
агрегаты). Ядро и стор не трогаются.

## Объём

- `Sources/SecondBrain/FineTune/TuningChatViewModel.swift` — `lastReport`.
- `Sources/SecondBrain/FineTune/FineTuneChatViews.swift` — два блока панели.
- Тест на `lastReport` (последний с отчётом; пусто → nil).

## Критерии приёмки

1. После каждого ответа блок «Последний запрос» показывает его вердикт, вызовы,
   latency и токены; блок «Сессия» — агрегаты треда; числа согласованы.
2. Последний ответ без отчёта → блок запроса не показывается, сессия работает.
3. `./scripts/build.sh`, `./scripts/test.sh` зелёные; ревью GO.

## Отчёт тестов

`testLastReportReturnsLatestAssistantReportOrNil`: пустой тред → nil; после send отчёт
есть; «последний, а не первый» — два засеянных ответа с разными вердиктами (.ok →
.fail), lastReport отдаёт .fail; смена варианта на пустой тред → nil. Консистентность
блоков — общий источник (messages активного треда, один проход body). Итог
`./scripts/test.sh`: **1627 тестов, 0 падений, 1 пропущен** (live-harness).

AX-value: оба блока в одном value панели («последний запрос: …; сессия: …»); живой
AX-прогон — хвост среды 85–89 (разрешение Accessibility), паттерн `.accessibilityElement
(children: .combine)` не менялся.

## Вердикт ревью

GO. Важные закрыты до коммита: тавтологичный ассерт заменён на засев двух вердиктов;
артефакты добавлены. Мелочи: маппинг вердикт→подпись/цвет унифицирован extension'ом
`ConfidenceVerdict.uiLabel/uiColor` (была третья копия), `lastReport` передаётся
параметром в accessibility-хелпер, заглушка AX приведена к слову «статистика».

## Результат

Панель разделена: «Последний запрос» — вердикт-чип + вызовы (всего/доп.), latency
(ответ/полная), токены именно последнего ответа; «Сессия» — прежние агрегаты треда.
Заголовок общий «Статистика — Базовая/Тюн». Сравнение вклада запроса и фона сессии
теперь прямое.
