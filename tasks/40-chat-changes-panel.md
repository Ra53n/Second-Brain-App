# Задача 40. Вкладка «Изменения» в чате: diff'ы агента + git-обзор с коммитом

## Цель

Изменения, которые делает агент, видны не «свёрнутым блоком в пузыре сообщения», а отдельной вкладкой чата в стиле Claude Code: список файлов с раскрываемыми цветными diff'ами. Если рабочий каталог чата — git-репозиторий (проект или vault с GitHub), там же виден git-контекст: ветка/upstream/ahead-behind, незакоммиченный diff по файлам, отличия текущей ветки от main/master — и коммит/пуш прямо из вкладки.

## Зависимости

39 (fileChanges в сообщениях, нижняя панель), 16 (GitClient), 21 (эффективный каталог чата).

## Объём работ

- [x] `Chat/ChatChangesModels.swift` — чистая логика: `DiffSplitter` (разбиение `git diff` на секции по файлам, счётчики +/−), `ChatChangesAggregator` (агрегат fileChanges по сообщениям, новые сверху), `GitChangesOverview` + `load(git:)` (ветка/upstream/ahead/behind/файлы/diff, отличия ветки от main/master через `diff base...HEAD`, кап 256 КБ).
- [x] `Chat/ChatChangesView.swift` — панель: секция «В этом чате» (карточки операций агента с diff'ами и временем), секция «Git» (шапка ветки, файлы без diff-секций строками, `FileDiffCard` на файл, поле сообщения + «Закоммитить» / «Закоммитить и запушить», «Запушить N» при чистом дереве с ahead, свёрнутая секция «Отличия ветки от main/master»), пустые состояния («агент ещё не менял», «не git-репозиторий», «дерево чистое»).
- [x] `DiffTextView` (ToolApprovalViews) перерисован в стиле Claude Code: подсветка фоном на всю строку (+ зелёный, − красный, @@ синий), перенос длинных строк, выделяемый текст — общий для карточки approve, блока в сообщении и вкладки.
- [x] `ChatViewModel.ChatGitBridge` (overview/commit/push по эффективному каталогу чата) + проводка в AppModel через `GitClient` (создаётся на вызов).
- [x] Кнопка-переключатель «Изменения · N» в нижней панели (N — операции агента в чате); вкладка заменяет ленту сообщений, нижняя панель и поле ввода остаются; при смене чата вкладка закрывается.

## Вне объёма

- Инлайн-редактирование diff'а и частичный (по файлам) коммит — git add всего дерева, как в панели синка.
- Создание/переключение веток из вкладки.
- Постраничный просмотр гигантских diff'ов (кап 256 КБ с пометкой).
- Pull/fetch из вкладки (есть в панели синка vault).

## Критерии приёмки

- [x] `swift build` / `swift test` зелёные; новые тесты: DiffSplitterTests (мультифайловый git-diff, plain unified diff, пустой), ChatChangesAggregatorTests (порядок «новые сверху», пустые), GitChangesOverviewTests на temp-репо (не-репозиторий, чистое дерево, незакоммиченный diff, ветка против main, commitAll чистит дерево).
- [x] Вживую: вкладка открывается кнопкой в нижней панели, показывает diff'ы операций агента и git-состояние каталога; коммит из вкладки создаёт коммит и дерево чистеет.

## Результат

Выполнено 2026-07-18. 944 теста зелёные (было 934).

Решения:
- Вкладка заменяет ленту сообщений, а не открывается шитом/инспектором: нижняя панель и поле ввода остаются на месте — можно писать агенту, глядя на diff'ы (паттерн Claude Code «ctrl+g»-вью).
- Git-мост создаёт `GitClient` на вызов: операции вкладки редкие и короткие, FIFO-очередь клиента важна только внутри вызова; кэш клиентов не нужен.
- Коммит — `commitAll` (git add -A + commit), как в панели синка задачи 16; частичный коммит по файлам — вне объёма.
- «Отличия ветки от базы» показываются только когда текущая ветка ≠ main/master и база существует локально.

Агентам следующих задач: секции diff'а строит чистый `DiffSplitter` — если появится постраничность/сворачивание больших diff'ов, менять там; `GitChangesOverview.load` изолирован от AppModel и тестируется на temp-репо.
