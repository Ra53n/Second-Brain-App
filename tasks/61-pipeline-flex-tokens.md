# Задача 61: гибкий конвейер и экономия токенов (caveman, ast-index)

## Цель

Конвейер перестаёт сжигать токены на задачах, которым не нужны субагенты: малая задача
(новый дефолт) выполняется техлидом соло с обязательным `reviewer`-гейтом, полный конвейер —
только по явным триггерам. Плюс инструменты экономии: caveman (сжатие output) и ast-index
(навигация по символам вместо чтения файлов).

## Зависимости

Нет (правит процесс, не код).

## Объём

1. `CLAUDE.md`: дедупликация логики уровней (была в 4 местах), новая таблица уровней с
   дефолтом «малая», перенос шаблонов в `docs/CONVENTIONS.md`, правило ast-index в
   «Экономии контекста».
2. `.claude/skills/task-run/SKILL.md`: новый порог уровней и раскладка стадий.
3. `.claude/agents/architect.md`: ARCHITECTURE.md — грепом, структура кода — ast-index.
4. Все 9 `.claude/agents/*.md`: строка телеграфного стиля отчёта.
5. Установка caveman (хуки + скиллы + statusline, глобально в `~/.claude`) и ast-index
   (`~/.local/bin`, индекс в `~/Library/Caches/ast-index`).

## Вне объёма

- Код `Sources/`, тесты, скрипты `scripts/`.
- Модульные `Sources/**/CLAUDE.md` (сжатие — отдельным заходом при желании).
- `task-verify`/`task-new`/`task-plan` — их текст уровне-независим, правка не потребовалась.

## Результат

Выполнена в сессии 2026-07-26 (процессная правка, без кода — solo).

- `CLAUDE.md`: 42 013 Б → 37 012 Б (−12%; основной объём — таблицы и код, они не жмутся);
  уровни описаны один раз, дефолт — «малая» (техлид соло +
  `reviewer`-гейт), полная — по триггерам (новый модуль/persist/экран/инвариант/объём);

  `caveman-stats` в `~/.claude/skills`. Режим по умолчанию `full`. Cavecrew-субагенты
  намеренно не ставились — у проекта свои роли; вместо них в 9 агентов добавлена строка
  телеграфного стиля.

  индекс 277 файлов / 9533 символа в `~/Library/Caches/ast-index` (вне репо, gitignore не
  нужен). Пересборка после правок: `ast-index update`.
- Важно следующим агентам: caveman-хук глобальный (все проекты машины); statusline в
  `settings.json` перезаписан caveman'ом; уровень задачи теперь выбирается по триггерам —
  не откатывайся на «не уверен → полная».
