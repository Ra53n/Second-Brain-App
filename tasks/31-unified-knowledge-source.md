# 31 — Единый источник знаний чата

## Цель
Убрать смешение миров: в одном чате RAG ретривил из vault (личные заметки), а /help и git-инструменты смотрели на репозиторий проекта — модель получала противоречащие контексты («это не программный проект» vs Swift-код). Теперь у чата ОДИН источник знаний: vault ИЛИ репозиторий проекта; RAG, /help и инструменты согласованы.

## Зависимости
14 (RAG в чате), 25 (RAG доков), 28 (чип «База»).

## Объём работ
- [ ] `ChatConfiguration.knowledgeSource: vault|project` (migration-safe, незнакомое → vault).
- [ ] ragProvider маршрутизирует по источнику: vault → RagIndexManager, project → ретрив из project-docs.sqlite с источниками-цитатами (`ProjectDocsIndexService.retrievalOutcome`).
- [ ] Чип «База: Vault · N» / «База: Проект · N» + переключатель источника в поповере; проектные состояния (репо не выбран / индекс построится при первом вопросе / готов).
- [ ] Тесты: миграция, ретрив с источниками, состояния чипа.

## Вне объёма
- Клик по источнику-доку проекта (файлы репо не резолвятся в vault — показываются некликабельными, это честно).
- Реранк/rewrite для проектного ретрива (top-K без реранка; при необходимости — бэклог).

## Критерии приёмки
- `swift build` и `swift test` зелёные.
- В чате с источником «Проект» вопрос «что это за проект?» отвечается по README/docs репозитория (без заметок vault); с источником «Vault» — по заметкам. Источник виден в чипе и переключается в два клика.

## Результат

Сделано (2026-07-18): всё из объёма. `KnowledgeSource` в конфиге чата; `ProjectDocsIndexService.retrievalOutcome` (общее ядро topHits с helpBlock) + `ProjectToolsProvider.projectRetrieval/docsChunkCount`; wireRagProvider ветвится по источнику; RagChipSummary/RagStatusChip с сегмент-пикером «Vault (заметки) / Проект (репозиторий)» и проектными состояниями (repoMissing → «Выбрать репозиторий…», ленивый empty без ошибки). /help как и прежде отвечает по репозиторию — теперь это согласовано с выбором источника «Проект». Тесты: миграция (в т.ч. значение из будущего → vault), outcome с источниками, состояния чипа обоих источников. 657 тестов зелёные.
