# 04 — Wikilinks и backlinks

## Цель
Заметки связываются через `[[wikilinks]]` в Obsidian-совместимом синтаксисе: автокомплит при вводе, клик-переход, панель backlinks, парсинг frontmatter.

## Зависимости
03.

## Контекст
Связность — суть «второго мозга». Синтаксис Obsidian: `[[Имя заметки]]`, `[[Имя|алиас]]`, `[[Имя#Заголовок]]`; ссылки резолвятся по имени файла без расширения по всему vault (при дублях — кратчайший путь). Frontmatter — YAML между `---` в начале файла. Эталон стиля парсеров и их тестов: `PromptParsingTests.swift` в MA (round-trip, edge cases).

## Объём работ
- [ ] `Links/WikilinkParser.swift`: извлечение ссылок из текста (диапазоны + цель + алиас + заголовок), игнорирование код-блоков и инлайн-кода.
- [ ] `Links/FrontmatterParser.swift`: YAML frontmatter → словарь (достаточно плоских ключей: строки, числа, списки строк, даты) + сериализация обратно без потери остального текста.
- [ ] `Links/LinkIndex.swift`: индекс «кто на кого ссылается» по vault, инкрементальное обновление по FSEvents; резолв имени → файл.
- [ ] Редактор: ввод `[[` открывает автокомплит по именам заметок (fuzzy), Enter вставляет ссылку; клик (или Cmd+клик) по ссылке открывает заметку; ссылка на несуществующую заметку создаёт её (как в Obsidian).
- [ ] Панель backlinks у открытой заметки: список заметок-источников со сниппетом строки.
- [ ] Подсветка wikilinks в редакторе.

## Вне объёма
Graph view (19), переименование с обновлением всех ссылок (в 19, но LinkIndex проектируй так, чтобы это было возможно), embed `![[...]]`.

## Критерии приёмки
- Тесты парсеров: все формы ссылок, ссылки в код-блоках не считаются, кириллица/пробелы/эмодзи в именах, битый frontmatter не роняет парсер, round-trip frontmatter.
- Тесты LinkIndex: построение на temp-vault, обновление при изменении файла, резолв дублей.
- Ручная проверка на vault пользователя: его существующие ссылки резолвятся, backlinks совпадают с тем, что показывает Obsidian.

## Подсказки
- Не тащи YAML-библиотеку ради плоского frontmatter — простого парсера достаточно, но задокументируй ограничения в файловом заголовке.
- Регекс для wikilink обманчиво прост — сначала напиши тесты на `[[a|b]]`, `[[a#h|b]]`, `[[  ]]`, вложенные скобки.
