# Задача 57: промпты проверки сценарных профилей

## Тип

документация (проверить и закрыть уже готовые артефакты)

## Модель

haiku (проверка по чек-листу критериев, без архитектурной неопределённости)

## Цель

Для трёх профилей задачи 56 есть готовые промпты на реальных задачах проекта — по одному на
профиль, каждый исполняется в отдельной ветке своей итерации (`bugfix-1`, `research-1`,
`refactor-1`). Достаточно открыть свежую сессию, выбрать профиль и вставить промпт.

## Зависимости

56 (сами профили) — выполнена.

## Объём

1. `bench/profiles/{bugfix,research,refactor}/PROMPT.md` — три промпта: реальный баг
   (переименование ломает [[ссылки]], пункт 4 бэклога), реальный вопрос (слой разрешений
   инструментов), реальная область (модуль GitSync против правил проекта).
2. `bench/profiles/README.md` — как гонять и на что смотреть в отчёте.
3. `bench/.gitignore` — попутно починен якорь (`bench/out/` → `out/`): паттерн внутри `bench/`
   якорился к `bench/bench/out/`, и артефакты `capture.sh` не игнорировались.
4. `tasks/00-INDEX.md` — строка задачи.

## Вне объёма

- Засеянные дефекты, скрипты подготовки, рубрики и ключи оценки — осознанно не делаем,
  проверка на реальных задачах и по формату отчёта профиля.
- Сами прогоны: требуют свежих сессий без вмешательства.

## Критерии приёмки

1. Три самодостаточных `PROMPT.md`; каждый велит работать в отдельной ветке итерации и не
   трогать main; bugfix/refactor запрещают вопросы.
2. Баг для bugfix не чинится в main (фикс живёт в ветке) — корневой `bench/` не испорчен.
3. Секретов нет.

## Результат

Три готовых промпта на реальных задачах проекта (bugfix/research/refactor), README и
исправленный `.gitignore` были написаны в предыдущей сессии; в этой сессии — только верификация
по критериям приёмки, правок артефактов не потребовалось.

Замечание ревьюера (не блокирует): `bench/profiles/research/PROMPT.md` не содержит явного
«main не трогать», в отличие от bugfix/refactor — критерий формально требует этого от всех трёх.
Риска нет (`research` — read-only профиль, физически не может закоммитить), но формулировку
промпта стоит выровнять при следующей правке `bench/profiles/`.
