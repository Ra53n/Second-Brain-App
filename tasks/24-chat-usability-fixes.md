# 24 — Доступность моделей в чате и починка кнопки синхронизации

## Цель
Устранить блокеры UX, найденные smoke-тестом 2026-07-17: кнопка синка в тулбаре не открывает панель; в пикере модели все провайдеры серые без объяснения причин и пути решения; из чата непонятно, куда прописать API-ключ.

## Зависимости
12 (чат), 16 (git-синк), 17 (настройки).

## Контекст (находки smoke-теста)
1. Клик по «Синхронизация» (иконка pencil.circle) не открывает GitSyncPanel. Вероятная причина: `@State showsPanel` живёт во view внутри ToolbarItem — при перестройке тулбара (например, при переключении разделов или обновлении detail-тулбара чата) view пересоздаётся и state сбрасывается до показа поповера.
2. Пикер модели: пункты недоступных провайдеров задизейблены (`.disabled(!isAvailable)`) — пользователь видит серый список, не может ничего выбрать и не понимает почему.
3. Ключи вводятся в Настройки → Провайдеры, но из чата туда нет ни одной ссылки/подсказки.

## Объём работ
- [ ] Синк: перенести состояние показа панели в `SyncViewModel` (`@Published var showsPanel`), кнопка биндится на него; проверить открытие панели вживую.
- [ ] Пикер модели: снять `.disabled`, недоступные пункты помечать причиной («нет ключа» / «не запущен»); выбор недоступного провайдера сохраняется как переопределение чата.
- [ ] Пункт «Открыть настройки…» в пикере модели (`@Environment(\.openSettings)`) + footer-подсказка про ключи и локальные модели.
- [ ] Ошибка «провайдер недоступен» в чате дополняется подсказкой: ключи — Настройки → Провайдеры, локальные модели — вкладка «Локальные модели».
- [ ] Тесты: setModel сохраняет недоступного провайдера; errorText при отправке содержит подсказку про настройки.

## Вне объёма
- Автозапуск Ollama при выборе локальной модели (бэклог).
- Редизайн панели синка.

## Критерии приёмки
- `swift build` и `swift test` зелёные.
- Вживую: клик по кнопке синка открывает панель; в пикере модели можно выбрать любой провайдер, у недоступных видна причина; «Открыть настройки…» открывает окно настроек; при отправке без доступного провайдера баннер объясняет, где взять ключ.

## Результат

Сделано (2026-07-17):
- **Синк-кнопка**: состояние `showsPanel` перенесено из `@State` кнопки в `SyncViewModel` (`@Published`) — локальный state пересоздавался вместе с ToolbarItem при перестройке тулбара (detail-тулбар чата добавляет свои элементы), и поповер не показывался. Кнопка биндится на `$viewModel.showsPanel`.
- **Пикер модели** (ChatViews.swift): `.disabled` снят — недоступные провайдеры выбираемы (переопределение сохраняется в конфиг чата), причина в названии пункта: «(нет ключа)» для облачных, «(не запущен)» для локальных; добавлены пункт «Открыть настройки…» (`@Environment(\.openSettings)`) и footer-подсказка про вкладки «Провайдеры» и «Локальные модели».
- **Баннер ошибки**: к «провайдер недоступен» добавлена подсказка, где прописать ключ и где запустить локальные модели.
- **Тест**: `testUnavailableProviderSelectableAndErrorHintsSettings` — выбор недоступного провайдера сохраняется, errorText содержит путь к настройкам. Всего 607 тестов зелёные.

Ограничение проверки: клик по синк-кнопке вживую не прогнан автоматикой (клики блокирует слой виджетов Центра уведомлений, права Apple Events сброшены перезагрузкой) — фикс детерминированный (владение состоянием), просьба к пользователю кликнуть кнопку после обновления приложения.
