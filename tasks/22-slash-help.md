# 22 — Слэш-команда /help

## Цель
Команда `/help <вопрос>` в чате: ассистент отвечает на вопросы о выбранном проекте (структура, устройство, куда второй мозг подключается), используя README+docs выбранного репозитория как контекст и git-инструменты задачи 21 для уточнений.

## Зависимости
20 (документация — источник знаний), 21 (инструменты и настройка репозитория).

## Контекст
Слэш-команд в чате нет — механизм новый, закладывается расширяемым (реестр команд). Репозиторий берётся из `AppSettings.projectRepoPath` (задача 21).

## Объём работ
- [ ] `Chat/SlashCommands.swift`: разбор ввода (`/help вопрос` / `/help` / неизвестная команда / обычный текст), каталог команд для подсказок.
- [ ] `Tools/ProjectDocs.swift`: загрузка README.md + docs/*.md выбранного репозитория; сборка блока `[PROJECT_DOCS]` с бюджетом символов (32 000, README приоритетен, обрезка с пометкой).
- [ ] ChatPromptBuilder: секция `[PROJECT_DOCS]` + инструкция уточнять деталями через git-инструменты.
- [ ] ChatViewModel: рефакторинг send() → `startGeneration(...)` с переопределениями хода (docs-контекст, принудительные project-tools); `/help` без вопроса и неизвестная команда → локальный ответ-подсказка без вызова LLM; репозиторий не настроен → понятная ошибка; RAG-ретрив для /help-ходов пропускается; провайдер без tool-поддержки → docs без инструментов (не ошибка).
- [ ] Подсказка в поле ввода: при вводе `/...` показывать строку с доступными командами.

## Вне объёма
- Другие команды кроме /help (реестр расширяемый, но наполняется позже).
- Полноценный autocomplete с навигацией (бэклог, п. 17).
- Настраиваемый бюджет контекста (бэклог, п. 18); RAG-индексация доков (бэклог, п. 19).

## Критерии приёмки
- Тесты: разбор всех форм команды; сборка docs-блока (порядок, бюджет, пустота); /help через scripted-провайдера — system-промпт содержит [PROJECT_DOCS], инструменты включены даже при выключенном projectToolsEnabled; голый /help — локальный ответ без LLM; существующие тесты send() зелёные после рефакторинга.
- `swift build` и `swift test` зелёные.
- Вручную: `/help где хранятся чаты?` при выбранном репозитории Second Brain — ответ по DATA-MODEL.md; `/help` — подсказка; `/абракадабра` — «неизвестная команда».

## Результат

Сделано (2026-07-16):
- **Chat/SlashCommands.swift** — enum SlashCommand (help/helpUsage/unknown), разбор (`/`+буква, имя до пробела, регистронезависимо; «1/2» и «/ 5» — не команды), catalog для подсказок, usageText.
- **Tools/ProjectDocs.swift** — ProjectDocsLoader (README.md без учёта регистра + docs/*.md по алфавиту, файлы >256 КБ пропускаются) и ProjectDocsContext.build (бюджет 32 000 символов, README приоритетен, обрезка с пометкой, не вошедшие файлы перечисляются с советом читать через read_file).
- **ChatPromptBuilder** — секция `[PROJECT_DOCS]` с директивой отвечать о проекте и уточнять инструментами git_*/read_file.
- **ChatViewModel** — рефакторинг: тело send() вынесено в `startGeneration(chatIndex:userText:overrides:)` с приватным `TurnOverrides {wantsProjectDocs, forceProjectTools, skipsRag, allowsToolFallback}`; семантика истории (`dropLast(2).suffix(window) + [user]`) сохранена бит-в-бит — все старые тесты зелёные. `/help вопрос` идёт генерационным путём с доками и принудительными project-инструментами; `/help` и незнакомая команда — `appendLocalExchange` (локальный ответ без LLM, isLoading не включается); нет репозитория → `SlashHelpError.repositoryNotConfigured` в баннер; RAG-ретрив на /help-ходе пропускается; провайдер без function calling → graceful degradation (доки без инструментов), для обычных MCP-чатов поведение прежнее (ошибка).
- **UI** — подсказка команд над полем ввода, пока набирается «/имя» без пробела (полноценный autocomplete — бэклог п. 17). projectDocsProvider подключён в ContentView.wireProjectTools (чтение файлов вне главного потока), ProjectToolsProvider получил `currentRepoRoot()`.
- **Тесты** (SlashCommandTests.swift, 5 сьютов, 19 тестов): разбор всех форм; загрузчик (регистр README, сортировка, не-md); бюджет (обрезка, пропуск, пусто); секция промпта; поведение VM — доки+инструменты в запросе, `/help` в тексте сообщения как есть, локальные ответы без вызова LLM, ошибка без репозитория (заглушка убрана), деградация без tool-поддержки, RAG пропущен. Всего 599 тестов зелёные.

Отклонения: вместо передачи только вопроса модели уходит весь текст «/help вопрос» (прозрачность истории; модель поняла контекст по [PROJECT_DOCS]). Пустые доки при настроенном репозитории → модели явно сообщается «изучай инструментами».
