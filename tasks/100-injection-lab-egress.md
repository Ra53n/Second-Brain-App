# Задача 100: лаборатория indirect injection + детерминированные защиты (egress, санитизация тул-результатов)

фича

## Модель

новых модулей-экранов и persisted-типов не добавляется, объём — ~5 файлов Sources + стенд).

## Цель
Задача 99 закрыла текстовый слой только для `[RAG_CONTEXT]`/`[PROJECT_DOCS]`. Результаты
инструментов и MCP-ответы уходят в модель сырыми (`ChatToolAssembly` → `ToolUse.swift:240`),
а егресс-контроля в выводе нет вообще. Это ровно дыры из бэклога #56 (а, в). Реализовать
стенд из 3 векторов непрямой инъекции (домашка «День 12»), доказать заражение до защиты,
закрыть дыры тремя детерминированными/полудетерминированными слоями и доказать закрытие.

## Зависимости

## Допущения и corner-кейсы
- Фенс + правила — вероятностная защита; probe на слабой локальной 7B показывает, что B и C
  она продавливает. Детерминированную точку для C даёт egress-guard (слой 3); для B —
  детерминированно снимается только сокрытие (zero-width), авторитет режет фенс.
- ERROR-префикс тул-результата НЕ оборачивается — иначе ломается `ok`-флаг `ToolUseLoop`
  (`ToolUse.swift:239`, `!output.hasPrefix("ERROR")`).
- Egress-guard не портит легитимный markdown: относительные ссылки, локальные пути,
  wikilinks, code fences, домены, явно названные пользователем в этой сессии.
- Санитизация не должна портить обычный контент (кириллица, эмодзи, код) — как в задаче 99.
- `evil_mcp.py` ничего наружу не шлёт; домены из RFC 2606 (`*.example`) не существуют.

## Критерии приёмки
1. До защиты: заражение проходит хотя бы по векторам B и C (probe + живой прогон, чекпоинт A).
2. HTML-комментарии из недоверенного контента не доходят до модели.
3. Результаты инструментов и MCP приходят в модель обёрнутыми и санитизированными; `ERROR`
   проходит без обёртки.
4. FSM-rag-блок обёрнут (паритет с одиночным ходом).
5. Egress-guard обезвреживает внешний data-несущий URL/картинку в выводе; легитимный markdown
   не портится.
6. После защиты: C заблокирован детерминированно; B/A удерживаются на живом прогоне (чекпоинт B).
7. `./scripts/build.sh` и `./scripts/test.sh` зелёные; секретов в индексе нет.
