# Задача 58: юнит-тесты на непокрытое чистое ядро (уровень 1)

## Цель

Закрыть три реальные дыры в чистом ядре тестами эталонного стиля (табличные, с граничными
случаями). Пользователь напрямую этого не видит, но регрессии в векторной математике RAG,
детекторе код-блоков редактора и парсере frontmatter перестают проходить незамеченными.
Часть инициативы «двухуровневое тестирование» — это её уровень 1 (код); уровни 2 (смоук) и
цикл — задачи 59, 60.

## Зависимости

Нет. Модули (`RAG/RagVector`, `Editor/CodeRegionDetector`, `Links/FrontmatterParser`) давно
существуют и стабильны; задача добавляет только тесты.

## Допущения и corner-кейсы (Продукт, малая — техлид)

- **Кто/зачем.** Разработчик/агент; тесты ловят регрессию до коммита (`./scripts/test.sh`).
- **Границы входа обязательны** (правило `Tests/.../CLAUDE.md` п.6): пусто, один элемент,
  лимит, лимит+1, кириллица, эмодзи, битый ввод, «значение из будущего».
- **`FrontmatterParser` уже частично покрыт** в `LinksTests.swift` (14 упоминаний): новый файл
  НЕ дублирует, а добивает round-trip/сериализацию/скаляры/`unquote`/битый ввод. Сначала
  прочитать frontmatter-тесты в `LinksTests.swift`.
- **`RagVector` и `CodeRegionDetector`** — прямых юнит-тестов нет (`cosine`/`topK` — только
  косвенно через индекс; `CodeRegionDetector` — ноль). Здесь дыра настоящая.
- **Только чистые функции** — ни сети, ни диска, ни `NSTextView`; моки не нужны.

## Архитектура (малая — техлид)

- **Куда ложится.** Только `Tests/SecondBrainTests/` (плоско, конвенция `<Тема>Tests.swift`).
  Продовый код не трогаем — все три типа уже чистые `enum`/`struct` (P1).
- **Переиспользуем** стиль [ToolPermissionsTests.swift](../Tests/SecondBrainTests/ToolPermissionsTests.swift):
  таблицы случаев циклом, подпись в ассерте (`XCTAssertEqual(actual, expected, name)`).
- **Инварианты** не затрагиваются (тесты изолированы от машины разработчика по определению).
- **Существующие тесты не меняются** (кроме, возможно, точечного переноса дублей из
  `LinksTests.swift`, если tester сочтёт нужным — но по умолчанию не трогать).
- **Аналог MA не нужен** — подсистема не создаётся.

   (нет закрывающего `---` → весь файл тело); пустой/отсутствующий блок; `subscript` set/remove;

## Вне объёма

- Правка любого продового кода в `Sources/` (кроме нулевой — задача только про тесты).
- Тесты на модули без дыр (Search, LLM, Chat и т.д. уже покрыты).
- Опциональный 4-й модуль `Audio/RecordingTypes` — низкая ценность, не делаем.
- SwiftUI-вёрстка и UI-смоук — это уровень 2 (задача 59).

## Критерии приёмки

1. Три новых файла тестов существуют и собираются.
2. `./scripts/test.sh` зелёный; суммарное число тестов выросло, ни один существующий не упал.
3. В каждом файле есть граничные случаи из списка выше (пусто/лимит/кириллица/битый ввод).
4. Стиль — табличный с подписью в ассерте (эталон `ToolPermissionsTests`).
5. Доказательство «тест кусается»: для одного случая показать, что временная поломка строки
   логики краснит тест (в отчёте верификации, поломку откатить).
6. `## Отчёт тестов` от `tester` и `## Вердикт ревью` = `GO` от `reviewer` в этом файле.

## Отчёт тестов

**Покрыто (54 новых теста):**

  нулевому/пустому вектору; `cosine` на сонаправленных/ортогональных/противоположных/разной
  длины/NaN/Inf; `topK` при `k>count`, `k==count`, `k<=0` (0/−1/−100), пустой матрице,
  устойчивости порядка при равных score, матрице 2000 векторов, NaN-score.
- `CodeRegionDetectorTests.swift` — 17 кейсов (2 класса): пустая строка; незакрытый ` ``` `;
  ` ``` ` не с начала строки; инлайн в строке vs через `\n` (не матчится); соседние/множественные
  инлайны; кириллица+эмодзи в инлайне и блоке (UTF-16 через `NSString`); `isExcluded` на пустом
  списке, пересечении, касании, перекрытии на 1, нулевой длине.
- `FrontmatterParserTests.swift` — 13 кейсов, класс `FrontmatterParserAdditionalTests` (имя

  кириллица в ключах; `unquote` парных/непарных кавычек; наивный comma-split инлайн-списка;
  отрицательные/нулевые числа; форма-даты-невалидной-по-календарю; `subscript` remove/set без
  frontmatter; raw «`:` без ключа»; пустой блок.

**Найденные расхождения поведения (задокументированы тестом, продовый код НЕ тронут — вне объёма 58):**
1. `RagVector.swift:30-34` — `cosine` с `Infinity`-компонентой → `NaN` (защита `guard na>0`
   ложна для NaN, но не для `Infinity`; доходит `∞/∞`). Комментарий обещает `[-1,1]`.
2. `CodeRegionDetector.swift:20-23` — незакрытый ` ``` ` → `excludedRanges` пуст, содержимое
   после тройки не защищено; ` ```code``` ` в середине строки случайно ловится инлайн-регексом.
3. `FrontmatterParser.swift:64` — `"---\n---\nТело."` (пустой, но присутствующий блок) не
   byte-exact: `serialized()` при `entries.isEmpty` теряет маркеры `---\n---\n`. Единственный
   не-round-trip случай.
4. `FrontmatterParser.swift:180` — `["a,b", c]` → `.list(["\"a","b\"","c"])` (наивный split по
   запятой; задокументированное ограничение «не полноценный YAML», раньше без теста).

**Сознательно не покрыто:** типы скаляров без мутаций (уже в `LinksTests`); конкурентный доступ
(все три — чистые stateless-функции P1); интеграция `CodeRegionDetector` в парсеры (в их тестах).

**«Тест кусается»:** временная замена `RagVector.swift:34` на `return -dot(a,b)/(na*nb)` →
8 упавших ассертов (`testCosineOfParallelVectorsIsOne`: `-0.99999994 != 1.0`); правка откачена,
`git diff --stat Sources/` пуст.

**Итог `./scripts/test.sh`:** `Executed 1089 tests, with 0 failures`. Новых 54, существующие не
менялись и не падали.
