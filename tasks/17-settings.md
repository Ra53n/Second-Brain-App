# 17 — Настройки

## Цель
Единый экран настроек, собирающий всё настраиваемое: vault, провайдеры и ключи, роутинг «функция → модель», промпт раскладки встреч, локальные модели, MCP-серверы, git.

## Зависимости
07 (минимум). Секции для 09/11/15/16 включай по факту их готовности (проверь 00-INDEX.md): невыполненные разделы — заглушка «появится после задачи NN».

## Контекст
К этому моменту настройки размазаны по разделам (ключи, модели, MCP). Задача — свести в стандартное окно Settings (Cmd+,) со вкладками, ничего не потеряв. Эталон UI-паттернов: sheets MA (ProviderKeysView, ModelPickerView).

## Объём работ
- [ ] Окно Settings (SwiftUI `Settings` scene) со вкладками:
  - **Общие**: текущий vault (смена, недавние), скрытие dot-папок, авто-открытие последнего vault;
  - **Провайдеры**: список из ProviderRegistry, ввод/удаление API-ключей (KeyStore; поле показывает только «ключ задан»), проверка ключа кнопкой (лёгкий запрос);
  - **Модели**: роутинг функция → провайдер+модель (FunctionRouting из 07) — для транскрипции, summary встреч, чата по умолчанию, эмбеддингов, раскладки заметок; предупреждение при недоступном назначении;
  - **Встречи**: пользовательский промпт раскладки (из 11) с дефолтом и кнопкой «сбросить», папка по умолчанию, источник записи по умолчанию;
  - **Локальные модели**: перенести/встроить UI из 09 и 10 (Ollama-статус, idle-таймаут, модели);
  - **MCP**: список серверов из 15 (добавить/редактировать/вкл-выкл/статус);
  - **Синхронизация**: интервал авто-бэкапа, вкл/выкл, состояние remote (из 16).
- [ ] Единый `SettingsStore` (паттерн ChatStore; собрать разрозненные UserDefaults/сторы, migrate существующие значения — ничего не сбрасывать).
- [ ] Разделы, чьи задачи не сделаны, — аккуратные заглушки.

## Вне объёма
Новая функциональность: только сведение и UI. Изменение схем данных 07/09/11/15/16 — лишь при крайней необходимости, с миграцией.

## Критерии приёмки
- Тесты: миграция настроек из старых мест хранения (значения переезжают, не теряются), сериализация SettingsStore, валидация роутинга при недоступном провайдере.
- Ручная проверка: каждая вкладка меняет реальное поведение (сменить модель транскрипции → пайплайн 11 использует её; выключить MCP-сервер → инструменты пропали из чата); Cmd+, открывает окно.

## Подсказки
- SwiftUI `Settings` scene даёт стандартное окно с тулбар-вкладками бесплатно.
- Ключи никогда не отображай (только статус «задан»); кнопка «показать» не нужна.
