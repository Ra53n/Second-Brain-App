## Рекомендуемый порядок

`01 → 02 → 03 → 04 → 05` (ядро заметок) → `07 → 08` (LLM-фундамент) → `06 → 11` (встречи — главная фича) → `09 → 10` (локальные модели) → `12 → 13 → 14` (чат и RAG) → `15 → 16 → 17 → 18 → 19`.

Задачи с разными зависимостями можно менять местами (например, 16 git-sync можно делать сразу после 02).

## Журнал отклонений

Если задача выполнена с существенными отклонениями от описания — одна строка здесь со ссылкой на «Результат» в файле задачи.

- 2026-07-24: по опыту реального применения — задача 53 сделала полный 6-стадийный конвейер
  обязательным для любой содержательной задачи (решение принято без замера цены,
  `bench/RESULTS.md` не заполнен), и на небольших задачах это оказалось непропорционально
  дорого по токенам. Задача 55 вводит третий уровень «малая задача» между solo и полным
  конвейером и убирает найденные чистые потери (двойное чтение `CLAUDE.md`, дублирование
  build/test/UI-смоука, битый путь к AX-скрипту в `task-verify`).
- 2026-07-13: ядро (01–18) завершено. Задача 19 — не одна задача, а бэклог: перед выполнением пункта его нужно детализировать (Цель/Объём/Критерии) в 19-polish-backlog.md или отдельном файле `19a-….md`; приоритет финально выбирает пользователь.
- 18 — реализована ветка Б (ad-hoc): Developer ID сертификата в Keychain нет; ветка А включается в dist.sh автоматически при его появлении (см. «Результат» в 18-distribution.md).
- 2026-07-16: бэклог 19 переехал в единый [BACKLOG.md](BACKLOG.md); заведены задачи 20–23 (документация, git-инструменты чата, /help, полировка чата) — выполняются пачкой по решению пользователя.
- 2026-07-23: по итогам gen1 бенчмарка — конфиги v2 (задача 53): конвейер ролей стал ОБЯЗАТЕЛЬНЫМ для содержательных задач (техлид делегирует стадиям, артефакт-секции в файле задачи, ревью-гейт GO/NO-GO); верификация зашита в always-on правила; конвенция комментариев развёрнута с «плотное покрытие» на «минимум по делу ~10–15%». Задачи 47 и 52 не выполнены (52 — предмет бенчмарка).
- 2026-07-22: процесс разработки формализован задачами 44–46 (выполнены пачкой по решению пользователя). Правила проекта переехали в `CLAUDE.md` + модульные `CLAUDE.md` рядом с кодом; появились субагенты (`.claude/agents/`) и скиллы цикла (`.claude/skills/`).
