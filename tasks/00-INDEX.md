## Рекомендуемый порядок

`01 → 02 → 03 → 04 → 05` (ядро заметок) → `07 → 08` (LLM-фундамент) → `06 → 11` (встречи — главная фича) → `09 → 10` (локальные модели) → `12 → 13 → 14` (чат и RAG) → `15 → 16 → 17 → 18 → 19`.

Задачи с разными зависимостями можно менять местами (например, 16 git-sync можно делать сразу после 02).
