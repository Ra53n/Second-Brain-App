# Задача 66: `CLAUDE.md` для модуля `MCP/`

## Тип

документация

## Модель

haiku

## Цель

`Sources/SecondBrain/MCP/` — stdio-протокол JSON-RPC с внешними процессами-серверами,
самое хрупкое место по механике (частичные чтения буфера, корреляция по id), но описано
только в шапке `MCPConnection.swift`, не в модульном `CLAUDE.md`.

## Зависимости

Нет.

## Объём

1. Создать `Sources/SecondBrain/MCP/CLAUDE.md` по шаблону существующих модульных CLAUDE.md
   (пример — `Sources/SecondBrain/RAG/CLAUDE.md`).
2. «Что здесь живёт»: `MCPConnection` (stdio-фрейминг, корреляция id), `MCPManager`,
   `MCPProtocol`, `MCPServer`, `ProviderToolSupport` (конвертация MCP tool schema ↔ формат
   провайдера), `ToolUse`, `MCPServersSection` (UI настроек).
3. «Инварианты»/риски: что происходит при обрыве процесса сервера, частичном JSON во
   буфере, несовпадении id ответа — как это сейчас обрабатывается (описать по факту кода,
   не изобретать новое поведение).

## Вне объёма

Правка кода `MCP/`, изменение протокола.

## Критерии приёмки

- [ ] `Sources/SecondBrain/MCP/CLAUDE.md` создан, все обязательные секции на месте.
- [ ] Описаны конкретно: фрейминг stdio, корреляция id, поведение при обрыве процесса.
- [ ] `./scripts/build.sh` зелёный.
