# 12 — Чат

## Цель
Раздел «Чат»: разговоры с любой настроенной моделью (локальной или облачной), стриминг ответов, история чатов переживает перезапуск.

## Зависимости
08 (желательно и 09 — тогда сразу проверяется локальная модель).

## Контекст
Это «просто отдельный чат со своим вторым мозгом» из требований; знание vault добавит RAG (14), инструменты — MCP (15) — проектируй точки расширения. Эталон: `ChatViewModel.swift`, `ChatStore.swift`, `PromptBuilder` в `Models.swift` MA, UI-паттерн ContentView (NavigationSplitView + сайдбар чатов).

## Объём работ
- [ ] `Chat/ChatModels.swift`: Chat (id, название, сообщения, настройки: провайдер+модель+температура), ChatMessage (роль, текст, метрики: токены/время/стоимость — порт MessageMetrics MA); Codable со снисходительным `init(from:)`.
- [ ] `Chat/ChatStore.swift`: порт ChatStore MA (Application Support, атомарно, debounce-автосейв, .corrupt.json).
- [ ] `Chat/ChatViewModel.swift` (@MainActor): CRUD чатов, отправка сообщения через роутер (функция `.chat` — либо переопределение модели per-чат), **стриминг** в UI (AsyncThrowingStream из 07/08), отмена генерации, ошибки в UI (LocalizedError → баннер у сообщения).
- [ ] `Chat/PromptBuilder.swift`: порт из MA — базовый системный промпт + секции; заготовка под `[RAG_CONTEXT]` (14) и инструменты (15).
- [ ] UI: список чатов в sidebar раздела «Чат», окно диалога (рендер markdown ответов — переиспользуй рендер из 03), поле ввода (многострочное), пикер модели в тулбаре (все доступные из ProviderRegistry, локальные помечены), автоназвание чата по первому сообщению.

## Вне объёма
RAG (14), MCP-инструменты (15), FSM-пайплайн ответов из MA (бэклог 19), сравнение моделей.

## Критерии приёмки
- Тесты: миграция чатов (порт подхода MigrationTests), PromptBuilder (сборка с/без секций), логика ViewModel с MockChatProvider (отправка, стрим по кускам, отмена, ошибка провайдера).
- Ручная проверка: диалог с облачной моделью — ответ печатается постепенно; смена модели посреди чата работает; после перезапуска история на месте; выключить сеть — понятная ошибка, чат не портится.

## Подсказки
- Стриминг + debounce-автосейв: не пиши на диск каждый токен — обновляй сообщение в памяти, Combine-debounce сохранит.
- История в API — вся переписка каждый раз (как в MA, там об этом файловый заголовок Models.swift); стратегии обрезки контекста — пока просто окно последних N сообщений с настройкой.
