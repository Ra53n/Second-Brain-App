# Задача 88: читаемая и всегда видимая статистика сессии в чате тюнинга

## Тип

фича (малая)

## Модель

Fable 5

## Допущения и corner-кейсы

Живой фидбэк после 86/87: панель статистики — нечитаемая простыня в раскрывашке,
пользователь хочет видеть её всегда. Corner-кейсы: ответов нет → панель видна с
подсказкой-заглушкой (не скрыта); разрез «с доп. вызовами / без» показывается,
только когда есть обе группы; длинные числа токенов — форматирование с разделителем.

## Архитектура

Только `FineTuneChatViews.sessionStatsSection`: DisclosureGroup → всегда развёрнутая
секция. Заголовок + ряд цветных чипов вердиктов (Ответов / OK / UNSURE / FAIL) +
Grid с подписанными строками: «Повторный инференс» (N из M ответов, доп. вызовов),
«Latency» (ответ → с пайплайном, наценка), «Токены (cost)». VM и ядро не трогаются;
`TuningChatSessionStats.compute` остаётся прежним (nil → заглушка во View).

## Объём

- `Sources/SecondBrain/FineTune/FineTuneChatViews.swift`.

## Критерии приёмки

1. Панель видна всегда (и при пустом чате — с заглушкой), без раскрывашки.
2. Вердикты — цветные чипы; повторный инференс, latency и токены — отдельные
   подписанные строки; наценка и разрез читаемы.
3. `./scripts/build.sh` и `./scripts/test.sh` зелёные; ревью GO.

## Вердикт ревью

Круг 1 — NO-GO: нет смоук-артефакта для чисто UI-задачи, `accessibilityValue` на голом
VStack мог не всплыть в AX-дерево; смоук-сценарий не покрывал вкладку «Чат». Круг 2 —
**GO**: `.accessibilityElement(children: .combine)`, блок «Чат» в `smoke/finetune.txt`,
мелочи (одна привязка stats, `formattedTokens`) закрыты.

## Результат

Панель «Статистика сессии» всегда видна (пустой чат — заглушка-подсказка): цветные
чипы вердиктов (Ответов / OK / UNSURE / FAIL), подписанные строки «Повторный
инференс» (N из M · доп. вызовов), «Latency» («ответ X с → с пайплайном Y с,
наценка ×Z», разрез с/без доп. вызовов), «Токены (cost)» с группировкой разрядов.
Смоук-сценарий вкладки «Чат» дописан в `smoke/finetune.txt`.

Хвост (как в 85–87): прогнать `./scripts/ui.sh` по `smoke/finetune.txt` после выдачи
разрешения Accessibility — проверить value панели («статистика сессии: …»), заглушку
«пока нет ответов» и элементы вкладки «Чат» вместе с хвостами задач 85–87.
