# 03 — Markdown-редактор

## Цель
Открытая в дереве заметка редактируется и сохраняется автоматически; markdown читабельно рендерится.

## Зависимости
02.

## Контекст
Минимум для работы со вторым мозгом: правка текста без потери данных. Эталон автосохранения — debounce-паттерн MA (`ChatViewModel.init`, см. CONVENTIONS.md). Для рендера у MA есть собственный `MarkdownText.swift` (AttributedString) и подключённый пакет `swift-markdown-ui` — выбери одно (рекомендация: swift-markdown-ui для превью, NSTextView для редактирования).

## Объём работ
- [ ] `Editor/EditorViewModel.swift`: загрузка файла, отслеживание правок, автосохранение с debounce 500 мс + сохранение при потере фокуса/закрытии, атомарная запись.
- [ ] `Editor/MarkdownEditorView.swift`: редактор на NSTextView (через NSViewRepresentable) — моноширинный/обычный шрифт, подсветка заголовков/жирного/кода лёгким стилем (полноценный syntax highlight не обязателен).
- [ ] Переключатель или сплит «Редактор / Превью»; превью рендерит markdown.
- [ ] Конфликт внешнего изменения: если файл изменился на диске, пока открыт в редакторе без несохранённых правок — тихо перечитать; если правки есть — показать выбор (перечитать / сохранить свою версию рядом с суффиксом `(conflict)`), молча не перезаписывать.
- [ ] Создание новой заметки из sidebar сразу открывает её в редакторе с курсором в тексте.

## Вне объёма
Wikilinks/автокомплит (04), таблицы контента, vim-режимы, вставка изображений.

## Критерии приёмки
- Тесты: debounce-логика сохранения (через инжектируемые часы/scheduler), поведение при внешнем изменении (обе ветки), атомарность записи.
- Ручная проверка на vault пользователя: открыть заметку с кириллицей и длинным текстом, править — содержимое не теряется, внешняя правка в другом редакторе подхватывается.

## Подсказки
- НЕ используй TextEditor из SwiftUI для основного редактора — на больших файлах тормозит; NSTextView надёжнее.
- Атомарная запись: `Data.write(options: .atomic)` — как в ChatStore MA.
- FSEvents из задачи 02 уже сообщает об изменениях — подпишись, не заводи второй механизм.
