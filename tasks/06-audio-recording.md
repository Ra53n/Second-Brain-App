# 06 — Запись звука

## Цель
Запись встречи: микрофон и/или системный звук (голоса собеседников в Zoom/Meet), результат — аудиофайл в vault, готовый к транскрипции.

## Зависимости
02.

## Контекст
Главный рабочий сценарий пользователя — запись рабочих встреч с последующей транскрипцией (задача 11). Запись должна быть надёжной: упавшее приложение не должно терять уже записанное.

## Объём работ
- [ ] `Audio/MicrophoneRecorder.swift`: AVAudioEngine, запись в .m4a (AAC); уровень сигнала для индикации.
- [ ] `Audio/SystemAudioRecorder.swift`: системный звук через Core Audio process tap (`CATapDescription` / `AudioHardwareCreateProcessTap`, macOS 14.4+) — весь системный вывод; graceful fallback с понятным сообщением, если ОС старее или нет разрешения.
- [ ] `Audio/RecordingSession.swift`: комбинированный режим (микрофон + система в один файл через микс либо двухдорожечно — выбери проще и задокументируй), пауза/продолжение, запись стримится на диск чанками (crash-safe: файл валиден после kill -9).
- [ ] Файлы: `<vault>/Meetings/_recordings/YYYY-MM-DD HH-mm.m4a`; метаданные записи (длительность, режим, дата) — sidecar JSON рядом либо в Application Support (реши и задокументируй).
- [ ] UI: раздел «Встречи» — кнопка записи, таймер, индикатор уровня, выбор источника (микрофон / система / оба), список прошлых записей с плеером (AVPlayer).
- [ ] Разрешения: `NSMicrophoneUsageDescription` в Info.plist (run.sh), запрос разрешения на захват системного звука; статусы разрешений видны в UI.

## Вне объёма
Транскрипция (10, 11), диаризация (19), глобальный хоткей (19).

## Критерии приёмки
- Тесты: логика RecordingSession (переходы запись/пауза/стоп через мок-рекордеры), генерация имён файлов, парсинг sidecar-метаданных.
- Ручная проверка: записать минуту голоса с микрофона — файл играет; включить видео на YouTube и записать системный звук — голос из видео в записи; kill -9 во время записи — файл до момента убийства читается.

## Подсказки
- Process tap — новый и капризный API; смотри WWDC24 «Capture system audio» и заголовки CoreAudio/AudioHardwareTapping.h. Если совсем не взлетит — зафиксируй в «Результате» и оставь микрофонный режим (для встреч в переговорке его достаточно), систему — отдельной подзадачей.
- Пиши AAC сразу через AVAudioFile с настройками формата, без промежуточного WAV (минута WAV ~10 МБ).
- Захват системного звука требует TCC-разрешения (аналог Screen Recording) — при отладке через `swift run` разрешение выдаётся терминалу, у .app своё; проверяй оба сценария.
