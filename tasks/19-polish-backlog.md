## Бэклог (примерный приоритет — сверху вниз, финально решает пользователь)

1. **Сравнение провайдеров транскрипции** (после 08, 10, 11): одна запись → транскрипция всеми настроенными провайдерами параллельно → экран сравнения бок-о-бок + стоимость/время. Пользователь прямо просил возможность определить лучшего для своих задач. Эталон UI: ComparisonView в MA.
2. **Диаризация спикеров** (после 08): Deepgram/AssemblyAI отдают спикеров — размечать транскрипт «Спикер 1/2», давать переименовывать в заметке.
3. **Глобальный хоткей записи** (после 06): начать/остановить запись из любого приложения (Carbon RegisterEventHotKey или MASShortcut-подобное), пункт в menu bar со статусом записи.
4. **Переименование заметки с обновлением ссылок** (после 04): LinkIndex это уже умеет по данным — нужна операция и UI.
5. **Graph view** (после 04): визуализация графа ссылок (Canvas/SpriteKit, force-directed).
6. **Теги** (после 04): `#тег` и frontmatter tags — парсинг, панель тегов, фильтр.
7. **Шаблоны заметок** (после 03): папка Templates, подстановки {{date}}, {{title}}; шаблон встречи для 11.
8. **FSM-пайплайн ответов в чате** (после 12): порт полного planning→execution→validation→answer из MA для сложных вопросов (+swarm). Взвесь ценность — в MA это главная фича, здесь чат проще.
9. **Автозапись по календарю** (после 11): интеграция с Calendar.app (EventKit) — напоминание/автостарт записи в момент встречи, название встречи из события календаря (закрывает сценарий «название задано заранее» автоматически).
10. **Подтверждение MCP-вызовов** (после 15): режим confirm для destructive-инструментов.
11. **Автообновления** (после 18): Sparkle 2.
12. **Экспорт/печать заметки** (после 03): PDF/HTML.
13. **Индикатор стоимости** (после 08): счётчик потраченного по провайдерам за месяц (метрики уже собираются — MessageMetrics).
