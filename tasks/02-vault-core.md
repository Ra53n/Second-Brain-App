# 02 — Vault: файлы и папки

## Цель
Пользователь выбирает любую папку как vault (включая существующий Obsidian vault), видит дерево файлов, создаёт/переименовывает/удаляет файлы и папки; внешние изменения подхватываются автоматически.

## Зависимости
01.

## Контекст
Vault — источник истины (ARCHITECTURE.md, инвариант №1). Реальная тестовая цель: `/Users/kostyanikitin/Documents/Obsidian Vault/Second_Brain` — живой vault пользователя с кириллическими именами папок, `.obsidian/`, `.git/`, вложенными папками. Ничего в нём не ломать при ручных проверках.

## Объём работ
- [ ] `Vault/VaultManager.swift` (`@MainActor ObservableObject`): открытие папки через NSOpenPanel, security-scoped bookmark в UserDefaults (переживает перезапуск), недавние vault'ы.
- [ ] `Vault/VaultTree.swift`: модель дерева (рекурсивно), сортировка папки-сначала, скрытие dot-папок (`.obsidian`, `.git`, `.trash`) с настройкой.
- [ ] CRUD: создать заметку/папку/произвольный файл, переименовать, удалить (**в Корзину через `FileManager.trashItem`, не безвозвратно**), переместить (drag&drop в дереве — если просто; иначе контекстное меню «Переместить»).
- [ ] FSEvents-наблюдение за vault: внешние изменения (пользователь правит в Obsidian параллельно) обновляют дерево; дебаунс событий.
- [ ] Sidebar в ContentView показывает дерево; выбор файла публикует его для будущего редактора (детальная панель пока показывает имя/размер).
- [ ] Уникальный `vault-id` (hash пути) для будущих индексов в Application Support.

## Вне объёма
Редактирование содержимого (03), поиск (05), git (16).

## Критерии приёмки
- Тесты: модель дерева (построение из временной директории, сортировка, фильтрация dot-папок), CRUD-операции на temp-директории, генерация vault-id.
- Ручная проверка: открыть vault пользователя — дерево корректно с кириллицей; создать и удалить тестовую заметку; удалённое оказывается в Корзине.
- После перезапуска приложение само открывает последний vault.

## Подсказки
- Security-scoped bookmarks: `url.bookmarkData(options: .withSecurityScope)` + `startAccessingSecurityScopedResource`; для не-sandbox приложения не критично, но делаем сразу правильно — sandbox может появиться при дистрибуции.
- FSEvents: `FSEventStreamCreate` с latency ~0.3 c, либо DispatchSource на директории; MA не имеет аналога — пиши сам, но стиль сохраняй.
- Пути с кириллицей и пробелами — сразу тестируй (у пользователя «Финансы и активы» и т.п.).
