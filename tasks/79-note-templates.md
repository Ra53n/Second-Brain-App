# Задача 79: шаблоны заметок

## Тип

фича

## Модель

sonnet

## Цель

Пользователь создаёт заметку из шаблона (папка `Templates/` в vault) вместо пустого файла —
с подстановкой `{{date}}`/`{{title}}` (`tasks/BACKLOG.md` п.7). Экономит повторяющийся
ручной ввод структуры (например, ежедневные заметки, шаблон встречи).

## Зависимости

Нет.

## Объём

1. Конвенция расположения: папка `Templates/` в корне vault (аналогично `Meetings/` —
   зарезервированное имя, см. существующие соглашения по спецпапкам в `Vault/`).
2. Точка входа: команда «Новая заметка из шаблона» (там, где уже есть «Новая заметка») —
   список файлов из `Templates/`, выбор одного.
3. Подстановка при создании: `{{date}}` → текущая дата в принятом в проекте формате,
   `{{title}}` → введённое пользователем имя новой заметки. Не найденные плейсхолдеры
   (опечатка вида `{{Date}}`) остаются как есть — не выбрасывать исключение.
4. Corner-кейсы: папки `Templates/` нет — пункт меню скрыт или показывает пустой список с
   понятной подсказкой; шаблон пуст — создаётся пустая заметка с именем без ошибки.

## Вне объёма

Редактор шаблонов внутри приложения (шаблоны — обычные .md-файлы, редактируются как любая
заметка), вложенные подпапки шаблонов, шаблоны с произвольными плейсхолдерами сверх
`{{date}}`/`{{title}}`.

## Критерии приёмки

- [x] Создание заметки из шаблона с `{{date}}` и `{{title}}` даёт файл с подставленными
      значениями.
- [x] Отсутствие папки `Templates/` не ломает создание обычной заметки.
- [x] Тест на подстановку плейсхолдеров (чистая функция, без реального диска) в
      `Tests/SecondBrainTests/`.
- [x] UI-точка входа проверена через `./scripts/ui.sh`.
- [x] `./scripts/build.sh` и `./scripts/test.sh` зелёные.

## Допущения и corner-кейсы

- `Templates/` — плоский список файлов (не рекурсивно), любое расширение, не только
  `.md` — сузить проще, чем расширять задним числом; вне объёма явно исключает подпапки.
- Пустое имя заметки при создании из шаблона → фолбэк `"Без названия"` (как у обычной
  «Новая заметка»), но кнопка «Создать» в шите заблокирована, пока имя пусто — так
  фолбэк реально не используется, оставлен как защита от гонки.
- `{{title}}` подставляется как введено пользователем, без санитайза под ФС — санитайз
  уже делает `VaultFileOperations.createNote`/`validate` при выборе имени файла.
- Шаблон читается best-effort (`try?`): нечитаемый файл (бинарник под `.md`, encoding)
  трактуется как пустой шаблон, не ошибка — не хуже, чем «шаблон пуст» из ТЗ.

## Архитектура

- Конвенция спецпапки: строкового реестра «зарезервированных папок» в `Vault/` нет —
  `Meetings/` зашита литералом в `MeetingNoteWriter`. `Templates/` сделан так же:
  константа `NoteTemplate.folderName`, без общего реестра (не создаю абстракцию под
  единственный второй случай).
- `NoteTemplate.render` — чистая функция (P1), зеркалит `PipelineTemplate.render`
  (тот же формат даты `yyyy-MM-dd`, `en_US_POSIX`, инъекция `date`/`timeZone` для тестов).
- `VaultFileOperations.createNote` расширен необязательным `content:` (была только
  пустая заметка) — переиспользование вместо новой CRUD-операции (P3), обратная
  совместимость по умолчанию.
- `VaultManager.templateFiles` — computed property поверх уже загруженного `root`
  (без лишнего I/O); `createNote(fromTemplate:title:)` — через существующий `perform`
  (та же публикация ошибок в `lastError`, тот же `open(result)`).
- UI: `TemplatePickerSheet` (новый приватный view в `VaultViews.swift`) — шит с Picker
  шаблонов + TextField имени; пустой список рендерит `ContentUnavailableView` с
  подсказкой вместо краша/пустого алерта. Точка входа продублирована в контекстном меню
  узла, контекстном меню корня и тулбаре — рядом с «Новая заметка» везде.

## Отчёт тестов

- `NoteTemplateTests` (6 тестов): `{{date}}`/`{{title}}`, неизвестный плейсхолдер
  остаётся как есть, пустой шаблон, шаблон без плейсхолдеров, повторный плейсхолдер,
  дата на границе полуночи по таймзоне.
- `VaultManagerTests` (+2): `templateFiles` пуст без папки и не ломает обычную
  «Новая заметка»; путь `TemplatePickerSheet.onCreate → createNote(fromTemplate:title:)`
  на temp-vault — подстановка плейсхолдеров в реальном файле и пустой шаблон → пустая
  заметка без ошибки.
- `./scripts/build.sh` — Build complete, без новых предупреждений.
- `./scripts/test.sh` — 1154 теста, 0 падений (было 1146 после задачи 78, +8).
- UI: собрано и установлено (`./install.sh`), приложение перезапущено. Живой AX-смоук
  прошёл (не упёрся в таймаут, в отличие от задач 75/77/78): `check "Новая заметка из
  шаблона"` → PASS (кнопка в тулбаре), `click` открывает шит, `check "Нет шаблонов"` →
  PASS на реальном vault пользователя (там нет `Templates/`) — корректная подсказка,
  не крash и не пустой алерт; Escape закрывает шит, `check "Ничего не выбрано"` → PASS
  (состояние приложения не нарушено, живой vault не тронут). Трассировка: тулбар/меню
  кнопка «Новая заметка из шаблона» → `showingTemplatePicker = true` →
  `TemplatePickerSheet` → `VaultManager.createNote(fromTemplate:title:)` →
  `VaultFileOperations.createNote(in:named:content:)`. Выбор конкретного файла-шаблона
  и подстановку в реальном UI не гонял (потребовало бы создать `Templates/` в живом
  vault пользователя — запрещено правилами проекта); этот путь закрыт интеграционным
  тестом на temp-vault.

## Результат

«Новая заметка из шаблона» — папка `Templates/` (плоский список, без подпапок), подстановка
`{{date}}`/`{{title}}` через чистую `NoteTemplate.render` (зеркалит `PipelineTemplate.render`),
создание файла через расширенный `VaultFileOperations.createNote(content:)`. `GO` с первого
круга — инвариант №1 не нарушен, обратная совместимость `createNote` сохранена, живой
AX-смоук на реальном vault прошёл без известной проблемы AX-таймаутов (задачи 75/77/78).

Точка входа продублирована в контекстном меню узла, контекстном меню корня и тулбаре.
