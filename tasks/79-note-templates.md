# Задача 79: шаблоны заметок

## Тип

фича

## Модель

sonnet

## Цель

Пользователь создаёт заметку из шаблона (папка `Templates/` в vault) вместо пустого файла —
с подстановкой `{{date}}`/`{{title}}` (`tasks/BACKLOG.md` п.7). Экономит повторяющийся
ручной ввод структуры (например, ежедневные заметки, шаблон встречи).

## Зависимости

Нет.

## Объём

1. Конвенция расположения: папка `Templates/` в корне vault (аналогично `Meetings/` —
   зарезервированное имя, см. существующие соглашения по спецпапкам в `Vault/`).
2. Точка входа: команда «Новая заметка из шаблона» (там, где уже есть «Новая заметка») —
   список файлов из `Templates/`, выбор одного.
3. Подстановка при создании: `{{date}}` → текущая дата в принятом в проекте формате,
   `{{title}}` → введённое пользователем имя новой заметки. Не найденные плейсхолдеры
   (опечатка вида `{{Date}}`) остаются как есть — не выбрасывать исключение.
4. Corner-кейсы: папки `Templates/` нет — пункт меню скрыт или показывает пустой список с
   понятной подсказкой; шаблон пуст — создаётся пустая заметка с именем без ошибки.

## Вне объёма

Редактор шаблонов внутри приложения (шаблоны — обычные .md-файлы, редактируются как любая
заметка), вложенные подпапки шаблонов, шаблоны с произвольными плейсхолдерами сверх
`{{date}}`/`{{title}}`.

## Критерии приёмки

- [ ] Создание заметки из шаблона с `{{date}}` и `{{title}}` даёт файл с подставленными
      значениями.
- [ ] Отсутствие папки `Templates/` не ломает создание обычной заметки.
- [ ] Тест на подстановку плейсхолдеров (чистая функция, без реального диска) в
      `Tests/SecondBrainTests/`.
- [ ] UI-точка входа проверена через `./scripts/ui.sh`.
- [ ] `./scripts/build.sh` и `./scripts/test.sh` зелёные.
