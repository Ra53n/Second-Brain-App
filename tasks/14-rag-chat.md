# 14 — RAG в чате

## Цель
Чат отвечает по содержимому vault: вопрос → релевантные чанки → ответ с цитатами-ссылками на заметки, ссылки открывают заметку.

## Зависимости
12, 13.

## Контекст
Пользовательский сценарий: «в чате по своей базе быстро искать нужную информацию». Эталон: `RagRetriever.swift` (эмбеддинг запроса, top-K, токен-бюджет контекста) и `RagRerank.swift` (LLM-переранжирование, переписывание запроса, форматирование цитат) в MA; `[RAG_CONTEXT]`-секция PromptBuilder уже заготовлена задачей 12.

## Объём работ
- [ ] Портировать `RAG/Retriever.swift`: эмбеддинг запроса (та же модель, что у индекса), top-K по косинусной близости, порог релевантности, токен-бюджет на контекст.
- [ ] Портировать rerank/query-rewrite как **опции** (выкл по умолчанию — лишние LLM-вызовы; включаются в настройках чата).
- [ ] Тумблер «Отвечать по базе» per-чат (persisted в настройках чата); при включении: retrieval → `[RAG_CONTEXT]` с чанками (каждый подписан источником: имя заметки + заголовок) → инструкция модели цитировать источники в формате `[[Имя заметки]]`.
- [ ] Рендер ответа: `[[wikilinks]]` в сообщениях кликабельны → открывают заметку в разделе «Заметки» (переиспользуй резолвер из 04).
- [ ] Под ответом — блок «Источники»: использованные чанки (заметка + заголовок + релевантность), клик открывает заметку.
- [ ] Пустой/нерелевантный результат: модель должна честно сказать «в базе не нашлось» (инструкция в промпте), а не галлюцинировать.

## Вне объёма
Индексация (13), агентные многошаговые ответы (19).

## Критерии приёмки
- Тесты: retriever на HashingEmbedder + `:memory:`-индексе (top-K порядок, порог, токен-бюджет режет по границе чанка), сборка `[RAG_CONTEXT]` (формат, подписи источников), извлечение источников из ответа, резолв wikilink из сообщения чата.
- Ручная проверка на vault пользователя: вопрос, ответ на который точно есть в заметках (например, по содержимому «Управление командой») — ответ ссылается на правильные заметки, ссылки открываются; вопрос не по базе — честное «не нашёл».

## Подсказки
- Качество на русском сильно зависит от модели эмбеддингов — дефолт разумно облачный (OpenAI text-embedding-3-small), локальный как опция; порекомендуй в UI.
- Cитаты-«галлюцинации» (ссылка на несуществующую заметку) валидируй резолвером и помечай в UI.
