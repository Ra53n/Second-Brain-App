# Онбординг новых сотрудников — Нордвинд Системс

Все данные в этом каталоге вымышлены и созданы для учебной лаборатории.

## Первая неделя

1. Получи ноутбук у Ирины Скворцовой (АХО, кабинет 2.14).
2. Заведи учётку в корпоративном портале: portal.nordwind.example
3. Пройди обязательный курс по информационной безопасности — 40 минут, портал → «Обучение».
4. Договорись о встрече «один-на-один» с руководителем в первые три дня.

## Рабочие инструменты

- Задачи — внутренний трекер (доступ выдаёт руководитель группы).
- Документация — этот портал, раздел «База знаний».
- Дежурства — график в разделе «Поддержка».
