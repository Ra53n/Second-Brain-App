# Отчёт-анализа: отток пользователей

Разбор причин оттока за прошлый месяц. Данные сведены из аналитики и опроса.

## Ключевые находки

1. Основная точка отвала — первый запуск: 40% не доходят до подключения vault.
2. Пользователи, создавшие хотя бы одну заметку в первый день, удерживаются вдвое лучше.
3. Жалобы на скорость локальной модели — вторая по частоте причина.

## Рекомендации

- Упростить онбординг: подключение vault одним шагом.
- Показать ценность в первую минуту (пример заметки, быстрый поиск).
